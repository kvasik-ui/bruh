Руководство пользователя: GnuPG (криптографическая защита данных)

1. Введение
1.1 Область применения. Шифрование и электронная подпись файлов и сообщений по схеме открытого ключа.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Шифрование и электронная подпись файлов и сообщений по схеме открытого ключа. Условия применения: Ubuntu 26.04 LTS; OpenSSL и GnuPG; KeePassXC для хранения ключей.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install intellij-idea-community --classic
sudo apt install openjdk-21-jdk maven -y
sudo apt install openssl gnupg keepassxc -y
sudo apt install postgresql postgresql-contrib -y
sudo apt install libpam-google-authenticator -y
openssl genpkey -algorithm RSA -out private.pem -pkeyopt rsa_keygen_bits:4096
3.2 Проверка работоспособности. Выполните команды:
java -version && mvn -version && openssl version
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. GnuPG работает командами gpg в терминале; KeePassXC запускается из меню приложений.

4. Описание операций
4.1 Операция 1. Создание ключевой пары
Условия выполнения: Установлен GnuPG.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните gpg --full-generate-key.
2. Выберите тип RSA, размер 4096 бит и срок действия.
3. Введите имя и адрес, задайте пароль.
Результат: ключевая пара создана.

4.2 Операция 2. Шифрование файла
Условия выполнения: Есть открытый ключ получателя.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните gpg --encrypt --recipient получатель файл.txt.
2. Проверьте наличие файла file.txt.gpg.
Результат: файл зашифрован.

4.3 Операция 3. Расшифровка файла
Условия выполнения: Есть закрытый ключ и пароль.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните gpg --decrypt file.txt.gpg > file.txt.
2. Введите пароль ключа.
Результат: файл расшифрован.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Потерян пароль ключа: расшифровка невозможна, храните пароль в KeePassXC. Скомпрометирован закрытый ключ: отзовите его командой gpg --gen-revoke и сообщите получателям.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Делайте резервную копию закрытого ключа в защищённом месте. Не храните закрытые ключи в открытом виде в репозитории. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
