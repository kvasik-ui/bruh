Руководство оператора: GnuPG (криптографическая защита данных)
Вариант задания № 18. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Шифрование и электронная подпись файлов и сообщений по схеме открытого ключа.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; OpenSSL и GnuPG; KeePassXC для хранения ключей.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo snap install intellij-idea-community --classic
sudo apt install openjdk-21-jdk maven -y
sudo apt install openssl gnupg keepassxc -y
sudo apt install postgresql postgresql-contrib -y
sudo apt install libpam-google-authenticator -y
openssl genpkey -algorithm RSA -out private.pem -pkeyopt rsa_keygen_bits:4096
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. GnuPG работает командами gpg в терминале; KeePassXC запускается из меню приложений.

3.3 Проверка работоспособности. Выполните команды:
java -version && mvn -version && openssl version
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Создание ключевой пары. Условия: установлен GnuPG.
   1. Выполните gpg --full-generate-key.
   2. Выберите тип RSA, размер 4096 бит и срок действия.
   3. Введите имя и адрес, задайте пароль.
   Результат: ключевая пара создана.
3.4.2 Шифрование файла. Условия: есть открытый ключ получателя.
   1. Выполните gpg --encrypt --recipient получатель файл.txt.
   2. Проверьте наличие файла file.txt.gpg.
   Результат: файл зашифрован.
3.4.3 Расшифровка файла. Условия: есть закрытый ключ и пароль.
   1. Выполните gpg --decrypt file.txt.gpg > file.txt.
   2. Введите пароль ключа.
   Результат: файл расшифрован.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Потерян пароль ключа: расшифровка невозможна, храните пароль в KeePassXC.
– Скомпрометирован закрытый ключ: отзовите его командой gpg --gen-revoke и сообщите получателям.
