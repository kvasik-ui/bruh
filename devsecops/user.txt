Руководство пользователя: DefectDojo (платформа управления уязвимостями)

1. Введение
1.1 Область применения. Централизованный учёт результатов сканирования безопасности: импорт отчётов SAST, отслеживание и закрытие уязвимостей.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Централизованный учёт результатов сканирования безопасности: импорт отчётов SAST, отслеживание и закрытие уязвимостей. Условия применения: Ubuntu 26.04 LTS; Docker и Docker Compose; ОЗУ не менее 8 ГБ.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/sast-env && source ~/sast-env/bin/activate
pip install semgrep bandit
sudo apt install wget apt-transport-https gnupg -y
wget -qO - https://aquasecurity.github.io/trivy-repo/deb/public.key | sudo gpg --dearmor -o /usr/share/keyrings/trivy.gpg
echo "deb [signed-by=/usr/share/keyrings/trivy.gpg] https://aquasecurity.github.io/trivy-repo/deb generic main" | sudo tee /etc/apt/sources.list.d/trivy.list
sudo apt update && sudo apt install trivy -y
sudo apt install docker.io docker-compose-v2 git -y
sudo systemctl enable --now docker
sudo docker pull zaproxy/zap-stable
git clone https://github.com/DefectDojo/django-DefectDojo.git
3.2 Проверка работоспособности. Выполните команды:
trivy --version && docker --version
~/sast-env/bin/semgrep --version && ~/sast-env/bin/bandit --version
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Запуск: sudo docker compose up -d в каталоге django-DefectDojo; вход через браузер на порту, указанном в документации.

4. Описание операций
4.1 Операция 1. Импорт отчёта SAST
Условия выполнения: DefectDojo запущен, создан продукт.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте раздел Findings → Import.
2. Выберите тип отчёта (например, Semgrep или Bandit) и файл JSON.
3. Нажмите Import.
Результат: результаты сканирования добавлены в систему.

4.2 Операция 2. Просмотр и закрытие уязвимости
Условия выполнения: Импорт выполнен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте найденную уязвимость из списка.
2. Измените статус: Mitigated или False Positive.
3. Сохраните изменения.
Результат: статус уязвимости обновлён.

4.3 Операция 3. Формирование отчёта
Условия выполнения: Есть данные по уязвимостям.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте раздел Reports.
2. Выберите продукт и формат отчёта.
3. Сохраните файл.
Результат: отчёт по уязвимостям сформирован.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Сервисы не запускаются: проверьте docker compose logs. Ошибка импорта: проверьте версию формата отчёта и выбранный тип сканера.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Настройте регулярные сканирования в конвейере CI/CD. Назначайте ответственных за каждую уязвимость. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
