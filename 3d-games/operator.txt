Руководство оператора: Git LFS (управление крупными ассетами)
Вариант задания № 3. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Хранение и версионирование крупных бинарных ресурсов игры (модели, текстуры, аудио) в репозитории Git.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; установленный Git 2.30 и новее; свободное место для ассетов не менее 10 ГБ.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
mkdir -p ~/godot && cd ~/godot
sudo apt install dotnet-sdk-8.0 -y
sudo apt install blender -y
sudo apt install gimp -y
sudo apt install git-lfs -y
git lfs install
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Git LFS работает через команды git; графический доступ — через GitKraken.

3.3 Проверка работоспособности. Выполните команды:
dotnet --version
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Отслеживание бинарных файлов. Условия: открыт репозиторий проекта; Git LFS установлен.
   1. Выполните: git lfs track "*.blend" "*.png" "*.wav".
   2. Проверьте файл .gitattributes командой cat .gitattributes.
   3. Добавьте .gitattributes в индекс: git add .gitattributes.
   Результат: крупные файлы будут храниться в LFS.
3.4.2 Добавление ассета и фиксация изменения. Условия: отслеживание настроено.
   1. Скопируйте ассет в каталог проекта.
   2. Выполните git add и git commit -m "Добавлен ассет".
   3. Отправьте изменения: git push.
   Результат: ассет зафиксирован в репозитории.
3.4.3 Проверка состояния LFS. Условия: в репозитории есть отслеживаемые файлы.
   1. Выполните git lfs ls-files.
   2. Убедитесь, что нужные файлы отмечены звёздочкой (загружены).
   Результат: состояние LFS-файлов известно.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Вместо ассета в репозитории находится короткий текстовый указатель: выполните git lfs pull.
– Ошибка авторизации при загрузке: проверьте учётные данные в GitKraken и доступ к серверу.
