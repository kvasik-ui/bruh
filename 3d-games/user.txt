Руководство пользователя: Git LFS (управление крупными ассетами)

1. Введение
1.1 Область применения. Хранение и версионирование крупных бинарных ресурсов игры (модели, текстуры, аудио) в репозитории Git.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Хранение и версионирование крупных бинарных ресурсов игры (модели, текстуры, аудио) в репозитории Git. Условия применения: Ubuntu 26.04 LTS; установленный Git 2.30 и новее; свободное место для ассетов не менее 10 ГБ.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
mkdir -p ~/godot && cd ~/godot
sudo apt install dotnet-sdk-8.0 -y
sudo apt install blender -y
sudo apt install gimp -y
sudo apt install git-lfs -y
git lfs install
3.2 Проверка работоспособности. Выполните команды:
dotnet --version
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Git LFS работает через команды git; графический доступ — через GitKraken.

4. Описание операций
4.1 Операция 1. Отслеживание бинарных файлов
Условия выполнения: Открыт репозиторий проекта; Git LFS установлен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните: git lfs track "*.blend" "*.png" "*.wav".
2. Проверьте файл .gitattributes командой cat .gitattributes.
3. Добавьте .gitattributes в индекс: git add .gitattributes.
Результат: крупные файлы будут храниться в LFS.

4.2 Операция 2. Добавление ассета и фиксация изменения
Условия выполнения: Отслеживание настроено.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Скопируйте ассет в каталог проекта.
2. Выполните git add и git commit -m "Добавлен ассет".
3. Отправьте изменения: git push.
Результат: ассет зафиксирован в репозитории.

4.3 Операция 3. Проверка состояния LFS
Условия выполнения: В репозитории есть отслеживаемые файлы.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните git lfs ls-files.
2. Убедитесь, что нужные файлы отмечены звёздочкой (загружены).
Результат: состояние LFS-файлов известно.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Вместо ассета в репозитории находится короткий текстовый указатель: выполните git lfs pull. Ошибка авторизации при загрузке: проверьте учётные данные в GitKraken и доступ к серверу.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Не храните в репозитории промежуточные файлы редактора. Настройте .gitignore для кэшей движка. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
