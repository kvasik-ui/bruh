Руководство пользователя: Jenkins (платформа CI/CD)

1. Введение
1.1 Область применения. Автоматизация сборки, тестирования и развёртывания приложений по конвейеру (pipeline).
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Автоматизация сборки, тестирования и развёртывания приложений по конвейеру (pipeline). Условия применения: Ubuntu 26.04 LTS; Java 17 или 21; ОЗУ не менее 4 ГБ; свободное место не менее 10 ГБ.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install code --classic
sudo apt install openjdk-21-jdk -y
sudo apt install docker.io docker-compose-v2 -y
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
sudo wget -O /usr/share/keyrings/jenkins-keyring.asc <АКТУАЛЬНЫЙ_URL_КЛЮЧА>
echo "deb [signed-by=/usr/share/keyrings/jenkins-keyring.asc] https://pkg.jenkins.io/debian-stable binary/" | sudo tee /etc/apt/sources.list.d/jenkins.list
sudo apt update
sudo apt install jenkins -y
sudo apt install prometheus golang-go ansible -y
3.2 Проверка работоспособности. Выполните команды:
sudo systemctl status jenkins --no-pager
sudo docker run --rm hello-world
sudo systemctl status prometheus --no-pager
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Откройте в браузере адрес http://localhost:8080 и войдите с начальным паролем.

4. Описание операций
4.1 Операция 1. Первичная настройка Jenkins
Условия выполнения: Служба Jenkins запущена, порт 8080 доступен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните sudo cat /var/lib/jenkins/secrets/initialAdminPassword и скопируйте пароль.
2. Вставьте пароль на странице входа и выберите установку рекомендованных плагинов.
3. Создайте администратора и сохраните настройки.
Результат: Jenkins готов к работе.

4.2 Операция 2. Создание конвейера сборки
Условия выполнения: Выполнен вход в Jenkins.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Нажмите New Item, введите имя и выберите Pipeline.
2. В разделе Pipeline вставьте сценарий Jenkinsfile.
3. Нажмите Save и затем Build Now.
Результат: сборка выполнена, в журнале (Console Output) видно результат.

4.3 Операция 3. Просмотр журналов сборок
Условия выполнения: Выполнена хотя бы одна сборка.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте задание и выберите номер сборки.
2. Перейдите в Console Output для просмотра журнала.
Результат: причина ошибок сборки найдена.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Jenkins не запускается: проверьте журнал командой sudo journalctl -u jenkins -n 50. Ошибка порта 8080: освободите порт или измените HTTP-порт в /etc/default/jenkins.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Храните сценарии сборки в репозитории вместе с кодом. Ограничьте права пользователей в разделе Manage Jenkins → Security. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
