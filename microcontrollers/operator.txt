Руководство оператора: Renode (эмулятор микроконтроллеров)
Вариант задания № 11. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Эмуляция микроконтроллеров ARM без физической платы для отладки и тестирования прошивки.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; ОЗУ не менее 4 ГБ; компилятор gcc-arm-none-eabi.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install gcc-arm-none-eabi gdb-multiarch -y
sudo apt install openocd -y
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/mcu-env && source ~/mcu-env/bin/activate
pip install platformio
sudo apt install ./renode_*.deb -y
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Запустите ~/renode/renode, затем в консоли Renode выполните команду запуска платформы.

3.3 Проверка работоспособности. Выполните команды:
renode --version
arm-none-eabi-gcc --version && openocd --version
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Сборка прошивки. Условия: установлен компилятор gcc-arm-none-eabi.
   1. Перейдите в каталог проекта.
   2. Выполните make (или команду сборки проекта).
   3. Проверьте наличие файла .elf.
   Результат: прошивка собрана в формате ELF.
3.4.2 Запуск прошивки в эмуляторе. Условия: прошивка собрана, Renode распакован.
   1. Запустите Renode командой ~/renode/renode.
   2. В консоли выполните команду загрузки платформы и файла прошивки.
   3. Запустите эмуляцию командой start.
   Результат: прошивка выполняется в эмуляторе.
3.4.3 Отладка через GDB. Условия: эмуляция запущена.
   1. Выполните arm-none-eabi-gdb файл.elf.
   2. Подключитесь к эмулятору командой target remote по порту из настроек Renode.
   3. Установите точку останова break main и продолжите выполнение.
   Результат: выполнение остановлено на точке останова.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Ошибка загрузки прошивки: проверьте путь к файлу и соответствие архитектуры платформе.
– Эмулятор зависает: завершите процесс командой pkill renode и запустите снова.
