Руководство пользователя: Renode (эмулятор микроконтроллеров)

1. Введение
1.1 Область применения. Эмуляция микроконтроллеров ARM без физической платы для отладки и тестирования прошивки.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Эмуляция микроконтроллеров ARM без физической платы для отладки и тестирования прошивки. Условия применения: Ubuntu 26.04 LTS; ОЗУ не менее 4 ГБ; компилятор gcc-arm-none-eabi.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install gcc-arm-none-eabi gdb-multiarch -y
sudo apt install openocd -y
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/mcu-env && source ~/mcu-env/bin/activate
pip install platformio
sudo apt install ./renode_*.deb -y
3.2 Проверка работоспособности. Выполните команды:
renode --version
arm-none-eabi-gcc --version && openocd --version
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Запустите ~/renode/renode, затем в консоли Renode выполните команду запуска платформы.

4. Описание операций
4.1 Операция 1. Сборка прошивки
Условия выполнения: Установлен компилятор gcc-arm-none-eabi.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Перейдите в каталог проекта.
2. Выполните make (или команду сборки проекта).
3. Проверьте наличие файла .elf.
Результат: прошивка собрана в формате ELF.

4.2 Операция 2. Запуск прошивки в эмуляторе
Условия выполнения: Прошивка собрана, Renode распакован.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Запустите Renode командой ~/renode/renode.
2. В консоли выполните команду загрузки платформы и файла прошивки.
3. Запустите эмуляцию командой start.
Результат: прошивка выполняется в эмуляторе.

4.3 Операция 3. Отладка через GDB
Условия выполнения: Эмуляция запущена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните arm-none-eabi-gdb файл.elf.
2. Подключитесь к эмулятору командой target remote по порту из настроек Renode.
3. Установите точку останова break main и продолжите выполнение.
Результат: выполнение остановлено на точке останова.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Ошибка загрузки прошивки: проверьте путь к файлу и соответствие архитектуры платформе. Эмулятор зависает: завершите процесс командой pkill renode и запустите снова.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Сначала проверяйте прошивку на эмуляторе, затем на плате. Сохраняйте скрипты запуска Renode в репозитории проекта. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
