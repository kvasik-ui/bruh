Руководство оператора: Apache JMeter (нагрузочное тестирование)
Вариант задания № 19. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Моделирование нагрузки на серверную часть онлайн-игры по HTTP и TCP и измерение времени отклика.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; OpenJDK 21; ОЗУ не менее 4 ГБ.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install g++ cmake libboost-all-dev -y
sudo apt install haproxy prometheus fail2ban ufw -y
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/game-env && source ~/game-env/bin/activate
pip install locust
sudo apt install jmeter -y
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Запустите JMeter командой jmeter или через меню приложений.

3.3 Проверка работоспособности. Выполните команды:
locust --version
g++ --version && haproxy -v | head -1
systemctl is-active prometheus fail2ban
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Создание тестового плана. Условия: JMeter запущен.
   1. Нажмите правой кнопкой по Test Plan → Add → Threads → Thread Group.
   2. Задайте число пользователей и время нарастания нагрузки.
   3. Добавьте HTTP Request с адресом сервера.
   Результат: тестовый план создан.
3.4.2 Запуск теста. Условия: тестовый план готов.
   1. Нажмите Start (зелёная стрелка).
   2. Наблюдайте за отчётами Summary Report и Aggregate Report.
   Результат: тест выполнен, результаты видны.
3.4.3 Анализ результатов. Условия: тест завершён.
   1. Откройте Aggregate Report.
   2. Проверьте средний отклик, процент ошибок и пропускную способность.
   Результат: узкие места выявлены.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Нехватка памяти JMeter: уменьшите число потоков или увеличьте heap в файле jmeter.
– Сервер не отвечает под нагрузкой: снизьте нагрузку и проверьте журналы сервера.
