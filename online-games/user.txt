Руководство пользователя: Apache JMeter (нагрузочное тестирование)

1. Введение
1.1 Область применения. Моделирование нагрузки на серверную часть онлайн-игры по HTTP и TCP и измерение времени отклика.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Моделирование нагрузки на серверную часть онлайн-игры по HTTP и TCP и измерение времени отклика. Условия применения: Ubuntu 26.04 LTS; OpenJDK 21; ОЗУ не менее 4 ГБ.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install g++ cmake libboost-all-dev -y
sudo apt install haproxy prometheus fail2ban ufw -y
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/game-env && source ~/game-env/bin/activate
pip install locust
sudo apt install jmeter -y
3.2 Проверка работоспособности. Выполните команды:
locust --version
g++ --version && haproxy -v | head -1
systemctl is-active prometheus fail2ban
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Запустите JMeter командой jmeter или через меню приложений.

4. Описание операций
4.1 Операция 1. Создание тестового плана
Условия выполнения: JMeter запущен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Нажмите правой кнопкой по Test Plan → Add → Threads → Thread Group.
2. Задайте число пользователей и время нарастания нагрузки.
3. Добавьте HTTP Request с адресом сервера.
Результат: тестовый план создан.

4.2 Операция 2. Запуск теста
Условия выполнения: Тестовый план готов.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Нажмите Start (зелёная стрелка).
2. Наблюдайте за отчётами Summary Report и Aggregate Report.
Результат: тест выполнен, результаты видны.

4.3 Операция 3. Анализ результатов
Условия выполнения: Тест завершён.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте Aggregate Report.
2. Проверьте средний отклик, процент ошибок и пропускную способность.
Результат: узкие места выявлены.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Нехватка памяти JMeter: уменьшите число потоков или увеличьте heap в файле jmeter. Сервер не отвечает под нагрузкой: снизьте нагрузку и проверьте журналы сервера.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Запускайте тест без графического интерфейса: jmeter -n -t plan.jmx -l results.jtl. Нагружайте только собственные тестовые стенды. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
