Руководство оператора: libnfc (RFID-считыватели и метки для WMS)
Вариант задания № 29. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Работа с RFID-считывателями и метками при учёте товаров на складе: чтение идентификаторов меток.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; USB-считыватель NFC, совместимый с libnfc; права sudo.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo snap install intellij-idea-community --classic
sudo apt install openjdk-21-jdk maven -y
sudo apt install libnfc-bin libnfc-dev -y
sudo apt install postgresql postgresql-contrib -y
sudo systemctl enable --now postgresql
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Проверка считывателя командой nfc-list; приложение WMS запускается из IntelliJ IDEA или командой java -jar.

3.3 Проверка работоспособности. Выполните команды:
java -version && mvn -version
nfc-list
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Подключение считывателя. Условия: считыватель подключён по USB.
   1. Выполните nfc-list.
   2. Убедитесь, что в выводе есть устройство и метка (при поднесении).
   Результат: считыватель распознан.
3.4.2 Чтение идентификатора метки. Условия: считыватель работает.
   1. Поднесите метку к считывателю.
   2. Выполните nfc-poll или nfc-list и запишите UID метки.
   Результат: UID метки получен.
3.4.3 Занесение данных в базу склада. Условия: база PostgreSQL создана, UID получен.
   1. Выполните INSERT в таблицу товаров с UID метки.
   2. Проверьте запись командой SELECT.
   Результат: товар связан с меткой в базе.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Считыватель не виден: проверьте подключение USB и файл настроек libnfc (/etc/nfc/libnfc.conf).
– Метка не читается: поднесите её ближе и повторите попытку.
