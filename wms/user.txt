Руководство пользователя: libnfc (RFID-считыватели и метки для WMS)

1. Введение
1.1 Область применения. Работа с RFID-считывателями и метками при учёте товаров на складе: чтение идентификаторов меток.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Работа с RFID-считывателями и метками при учёте товаров на складе: чтение идентификаторов меток. Условия применения: Ubuntu 26.04 LTS; USB-считыватель NFC, совместимый с libnfc; права sudo.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install intellij-idea-community --classic
sudo apt install openjdk-21-jdk maven -y
sudo apt install libnfc-bin libnfc-dev -y
sudo apt install postgresql postgresql-contrib -y
sudo systemctl enable --now postgresql
3.2 Проверка работоспособности. Выполните команды:
java -version && mvn -version
nfc-list
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Проверка считывателя командой nfc-list; приложение WMS запускается из IntelliJ IDEA или командой java -jar.

4. Описание операций
4.1 Операция 1. Подключение считывателя
Условия выполнения: Считыватель подключён по USB.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните nfc-list.
2. Убедитесь, что в выводе есть устройство и метка (при поднесении).
Результат: считыватель распознан.

4.2 Операция 2. Чтение идентификатора метки
Условия выполнения: Считыватель работает.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Поднесите метку к считывателю.
2. Выполните nfc-poll или nfc-list и запишите UID метки.
Результат: UID метки получен.

4.3 Операция 3. Занесение данных в базу склада
Условия выполнения: База PostgreSQL создана, UID получен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните INSERT в таблицу товаров с UID метки.
2. Проверьте запись командой SELECT.
Результат: товар связан с меткой в базе.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Считыватель не виден: проверьте подключение USB и файл настроек libnfc (/etc/nfc/libnfc.conf). Метка не читается: поднесите её ближе и повторите попытку.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Используйте метки с проверкой контрольной суммы. Регулярно делайте резервные копии базы склада. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
