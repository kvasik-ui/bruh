Руководство оператора: can-utils (симулятор CAN-шины на vcan)
Вариант задания № 17. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Имитация CAN-шины автомобильной информационно-развлекательной системы для проверки обмена сообщениями ECU.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; ядро с модулем vcan; права sudo.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo snap install code --classic
sudo apt install gcc-arm-none-eabi can-utils -y
sudo apt install cyclonedds-dev -y
sudo modprobe vcan
sudo ip link add dev vcan0 type vcan
sudo ip link set up vcan0
candump vcan0 &
cansend vcan0 123#DEADBEEF
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Виртуальный интерфейс создаётся командами ip link (см. раздел 4).

3.3 Проверка работоспособности. Выполните команды:
ip link show vcan0
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Создание виртуального CAN-интерфейса. Условия: модуль vcan загружен.
   1. Выполните sudo ip link add dev vcan0 type vcan.
   2. Включите интерфейс: sudo ip link set up vcan0.
   Результат: интерфейс vcan0 активен.
3.4.2 Отправка кадра. Условия: интерфейс vcan0 активен.
   1. Выполните cansend vcan0 123#DEADBEEF.
   Результат: кадр отправлен.
3.4.3 Приём кадров. Условия: интерфейс vcan0 активен.
   1. Выполните candump vcan0 в отдельном терминале.
   2. Отправьте кадр из другого терминала.
   Результат: кадр виден в выводе candump.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Ошибка Cannot find device vcan0: повторно выполните sudo modprobe vcan и создание интерфейса.
– Интерфейс пропал после перезагрузки: создайте его заново или добавьте скрипт автозапуска.
