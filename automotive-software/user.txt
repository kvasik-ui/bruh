Руководство пользователя: can-utils (симулятор CAN-шины на vcan)

1. Введение
1.1 Область применения. Имитация CAN-шины автомобильной информационно-развлекательной системы для проверки обмена сообщениями ECU.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Имитация CAN-шины автомобильной информационно-развлекательной системы для проверки обмена сообщениями ECU. Условия применения: Ubuntu 26.04 LTS; ядро с модулем vcan; права sudo.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install code --classic
sudo apt install gcc-arm-none-eabi can-utils -y
sudo apt install cyclonedds-dev -y
sudo modprobe vcan
sudo ip link add dev vcan0 type vcan
sudo ip link set up vcan0
candump vcan0 &
cansend vcan0 123#DEADBEEF
3.2 Проверка работоспособности. Выполните команды:
ip link show vcan0
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Виртуальный интерфейс создаётся командами ip link (см. раздел 4).

4. Описание операций
4.1 Операция 1. Создание виртуального CAN-интерфейса
Условия выполнения: Модуль vcan загружен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните sudo ip link add dev vcan0 type vcan.
2. Включите интерфейс: sudo ip link set up vcan0.
Результат: интерфейс vcan0 активен.

4.2 Операция 2. Отправка кадра
Условия выполнения: Интерфейс vcan0 активен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните cansend vcan0 123#DEADBEEF.
Результат: кадр отправлен.

4.3 Операция 3. Приём кадров
Условия выполнения: Интерфейс vcan0 активен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните candump vcan0 в отдельном терминале.
2. Отправьте кадр из другого терминала.
Результат: кадр виден в выводе candump.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Ошибка Cannot find device vcan0: повторно выполните sudo modprobe vcan и создание интерфейса. Интерфейс пропал после перезагрузки: создайте его заново или добавьте скрипт автозапуска.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Записывайте журнал кадров командой candump -l для анализа. Проверяйте работу приложения и на реальной шине перед выпуском. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
