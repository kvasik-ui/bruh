Руководство оператора: face_recognition (распознавание лиц для биометрических систем)
Вариант задания № 28. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Идентификация человека по изображению лица с использованием библиотек dlib и OpenCV.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; Python 3.10 и новее; компилятор g++ и cmake; ОЗУ не менее 8 ГБ.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install build-essential cmake libboost-all-dev python3-opencv python3-numpy python3-venv python3-pip -y
python3 -m venv --system-site-packages ~/bio-env && source ~/bio-env/bin/activate
pip install dlib face_recognition onvif-zeep
python -c "import cv2, face_recognition; print('OK')"
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Скрипты запускаются в активированном окружении: python identify.py.

3.3 Проверка работоспособности. Выполните команды:
python -c "import cv2, face_recognition; print('OK')"
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Регистрация лица. Условия: есть фото сотрудника в хорошем качестве.
   1. Загрузите фото командой face_recognition.load_image_file.
   2. Получите кодировку лица командой face_recognition.face_encodings.
   3. Сохраните кодировку в файл с именем сотрудника.
   Результат: лицо зарегистрировано.
3.4.2 Идентификация по кадру. Условия: есть зарегистрированные кодировки и кадр с камеры.
   1. Получите кадр через cv2.VideoCapture или поток камеры.
   2. Сравните кодировки командой face_recognition.compare_faces.
   Результат: совпадение найдено или отмечено как неизвестное.
3.4.3 Проверка точности. Условия: есть тестовый набор фото.
   1. Прогоните тестовый набор через скрипт.
   2. Подсчитайте долю правильных совпадений.
   Результат: точность системы известна.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Не устанавливается dlib: проверьте наличие cmake и build-essential.
– Низкое качество распознавания: улучшите освещение и разрешение кадра.
