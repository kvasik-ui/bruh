Руководство пользователя: face_recognition (распознавание лиц для биометрических систем)

1. Введение
1.1 Область применения. Идентификация человека по изображению лица с использованием библиотек dlib и OpenCV.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Идентификация человека по изображению лица с использованием библиотек dlib и OpenCV. Условия применения: Ubuntu 26.04 LTS; Python 3.10 и новее; компилятор g++ и cmake; ОЗУ не менее 8 ГБ.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install build-essential cmake libboost-all-dev python3-opencv python3-numpy python3-venv python3-pip -y
python3 -m venv --system-site-packages ~/bio-env && source ~/bio-env/bin/activate
pip install dlib face_recognition onvif-zeep
python -c "import cv2, face_recognition; print('OK')"
3.2 Проверка работоспособности. Выполните команды:
python -c "import cv2, face_recognition; print('OK')"
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Скрипты запускаются в активированном окружении: python identify.py.

4. Описание операций
4.1 Операция 1. Регистрация лица
Условия выполнения: Есть фото сотрудника в хорошем качестве.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Загрузите фото командой face_recognition.load_image_file.
2. Получите кодировку лица командой face_recognition.face_encodings.
3. Сохраните кодировку в файл с именем сотрудника.
Результат: лицо зарегистрировано.

4.2 Операция 2. Идентификация по кадру
Условия выполнения: Есть зарегистрированные кодировки и кадр с камеры.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Получите кадр через cv2.VideoCapture или поток камеры.
2. Сравните кодировки командой face_recognition.compare_faces.
Результат: совпадение найдено или отмечено как неизвестное.

4.3 Операция 3. Проверка точности
Условия выполнения: Есть тестовый набор фото.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Прогоните тестовый набор через скрипт.
2. Подсчитайте долю правильных совпадений.
Результат: точность системы известна.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Не устанавливается dlib: проверьте наличие cmake и build-essential. Низкое качество распознавания: улучшите освещение и разрешение кадра.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Храните биометрические данные в зашифрованном виде (GnuPG). Соблюдайте требования законодательства о персональных данных при работе с лицами. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
