Руководство пользователя: onvif-zeep (SDK для IP-камер)

1. Введение
1.1 Область применения. Управление IP-камерами по протоколу ONVIF: получение информации, потоков RTSP и параметров камеры.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Управление IP-камерами по протоколу ONVIF: получение информации, потоков RTSP и параметров камеры. Условия применения: Ubuntu 26.04 LTS; Python 3.10 и новее; OpenCV; FFmpeg и VLC для просмотра потоков.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install python3-opencv python3-numpy python3-venv python3-pip ffmpeg vlc -y
python3 -m venv --system-site-packages ~/cv-env && source ~/cv-env/bin/activate
pip install onvif-zeep
python -c "import cv2, onvif; print(cv2.__version__)"
3.2 Проверка работоспособности. Выполните команды:
python3 -c "import cv2; print(cv2.__version__)"
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Скрипты Python запускаются в активированном окружении: python script.py.

4. Описание операций
4.1 Операция 1. Подключение к камере
Условия выполнения: Известны IP-адрес, порт ONVIF, логин и пароль камеры.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Создайте скрипт с подключением ONVIFCamera(IP, 80, user, password).
2. Запросите информацию об устройстве командой device_service.GetDeviceInformation().
Результат: получены модель и версия камеры.

4.2 Операция 2. Просмотр видеопотока
Условия выполнения: Получен адрес потока RTSP.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните vlc rtsp://адрес_потока или ffplay rtsp://адрес_потока.
2. Проверьте картинку.
Результат: видеопоток отображается.

4.3 Операция 3. Распознавание объектов на кадре
Условия выполнения: OpenCV установлен, поток доступен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте поток через cv2.VideoCapture(адрес_rtsp).
2. Прочитайте кадр и выполните обработку.
Результат: кадр обработан, результат выведен.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Камера не отвечает: проверьте сеть (ping адрес_камеры) и порт ONVIF. Неверные учётные данные: проверьте логин и пароль в настройках камеры.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Меняйте стандартные пароли камер. Размещайте камеры и сервер в отдельной сети. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
