Руководство оператора: onvif-zeep (SDK для IP-камер)
Вариант задания № 20. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Управление IP-камерами по протоколу ONVIF: получение информации, потоков RTSP и параметров камеры.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; Python 3.10 и новее; OpenCV; FFmpeg и VLC для просмотра потоков.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install python3-opencv python3-numpy python3-venv python3-pip ffmpeg vlc -y
python3 -m venv --system-site-packages ~/cv-env && source ~/cv-env/bin/activate
pip install onvif-zeep
python -c "import cv2, onvif; print(cv2.__version__)"
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Скрипты Python запускаются в активированном окружении: python script.py.

3.3 Проверка работоспособности. Выполните команды:
python3 -c "import cv2; print(cv2.__version__)"
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Подключение к камере. Условия: известны IP-адрес, порт ONVIF, логин и пароль камеры.
   1. Создайте скрипт с подключением ONVIFCamera(IP, 80, user, password).
   2. Запросите информацию об устройстве командой device_service.GetDeviceInformation().
   Результат: получены модель и версия камеры.
3.4.2 Просмотр видеопотока. Условия: получен адрес потока RTSP.
   1. Выполните vlc rtsp://адрес_потока или ffplay rtsp://адрес_потока.
   2. Проверьте картинку.
   Результат: видеопоток отображается.
3.4.3 Распознавание объектов на кадре. Условия: OpenCV установлен, поток доступен.
   1. Откройте поток через cv2.VideoCapture(адрес_rtsp).
   2. Прочитайте кадр и выполните обработку.
   Результат: кадр обработан, результат выведен.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Камера не отвечает: проверьте сеть (ping адрес_камеры) и порт ONVIF.
– Неверные учётные данные: проверьте логин и пароль в настройках камеры.
