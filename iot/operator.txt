Руководство оператора: Mosquitto (симулятор IoT-устройств через брокер MQTT)
Вариант задания № 10. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Имитация обмена данными между IoT-устройствами и облаком через протокол MQTT без физических устройств.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; Python 3.10 и новее; права sudo.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/iot-env && source ~/iot-env/bin/activate
pip install platformio
pip install AWSIoTPythonSDK azure-iot-device
sudo apt install nodejs npm -y
sudo npm install -g --unsafe-perm node-red
sudo apt install mosquitto mosquitto-clients -y
sudo systemctl enable --now mosquitto
sudo apt install openssl -y
mosquitto_sub -t test/topic -C 1 &
mosquitto_pub -t test/topic -m "hello"
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Брокер запускается службой mosquitto; простые устройства имитируются скриптами Python.

3.3 Проверка работоспособности. Выполните команды:
node-red --version
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Публикация данных датчика. Условия: брокер Mosquitto запущен.
   1. Выполните mosquitto_pub -t sensors/temp -m "22.5".
   2. Убедитесь, что команда завершилась без ошибок.
   Результат: сообщение отправлено в топик sensors/temp.
3.4.2 Подписка на топик. Условия: брокер запущен.
   1. Выполните mosquitto_sub -t sensors/temp.
   2. Отправьте сообщение из другого терминала командой публикации.
   Результат: сообщение получено подписчиком.
3.4.3 Имитация устройства скриптом. Условия: установлена библиотека paho-mqtt, окружение активно.
   1. Создайте файл sim.py с подключением к localhost:1883.
   2. Запустите скрипт командой python sim.py.
   3. Проверьте получение данных подписчиком.
   Результат: устройство имитируется, данные передаются.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Брокер не запускается: проверьте журнал sudo journalctl -u mosquitto и порт 1883.
– Нет подключения клиентов: откройте порт командой sudo ufw allow 1883.
