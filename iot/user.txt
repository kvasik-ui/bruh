Руководство пользователя: Mosquitto (симулятор IoT-устройств через брокер MQTT)

1. Введение
1.1 Область применения. Имитация обмена данными между IoT-устройствами и облаком через протокол MQTT без физических устройств.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Имитация обмена данными между IoT-устройствами и облаком через протокол MQTT без физических устройств. Условия применения: Ubuntu 26.04 LTS; Python 3.10 и новее; права sudo.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/iot-env && source ~/iot-env/bin/activate
pip install platformio
pip install AWSIoTPythonSDK azure-iot-device
sudo apt install nodejs npm -y
sudo npm install -g --unsafe-perm node-red
sudo apt install mosquitto mosquitto-clients -y
sudo systemctl enable --now mosquitto
sudo apt install openssl -y
mosquitto_sub -t test/topic -C 1 &
mosquitto_pub -t test/topic -m "hello"
3.2 Проверка работоспособности. Выполните команды:
node-red --version
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Брокер запускается службой mosquitto; простые устройства имитируются скриптами Python.

4. Описание операций
4.1 Операция 1. Публикация данных датчика
Условия выполнения: Брокер Mosquitto запущен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните mosquitto_pub -t sensors/temp -m "22.5".
2. Убедитесь, что команда завершилась без ошибок.
Результат: сообщение отправлено в топик sensors/temp.

4.2 Операция 2. Подписка на топик
Условия выполнения: Брокер запущен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните mosquitto_sub -t sensors/temp.
2. Отправьте сообщение из другого терминала командой публикации.
Результат: сообщение получено подписчиком.

4.3 Операция 3. Имитация устройства скриптом
Условия выполнения: Установлена библиотека paho-mqtt, окружение активно.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Создайте файл sim.py с подключением к localhost:1883.
2. Запустите скрипт командой python sim.py.
3. Проверьте получение данных подписчиком.
Результат: устройство имитируется, данные передаются.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Брокер не запускается: проверьте журнал sudo journalctl -u mosquitto и порт 1883. Нет подключения клиентов: откройте порт командой sudo ufw allow 1883.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
В рабочих системах включите аутентификацию и TLS (сертификаты OpenSSL). Отделяйте топики по устройствам и типам данных. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
