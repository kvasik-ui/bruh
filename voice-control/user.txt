Руководство пользователя: Vosk (офлайн распознавание речи)

1. Введение
1.1 Область применения. Распознавание речи без подключения к интернету для голосового управления приложением.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Распознавание речи без подключения к интернету для голосового управления приложением. Условия применения: Ubuntu 26.04 LTS; Python 3.10 и новее; микрофон; PortAudio.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install portaudio19-dev ffmpeg python3-pip python3-venv -y
python3 -m venv ~/voice-env && source ~/voice-env/bin/activate
pip install vosk SpeechRecognition pyaudio
wget https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip
unzip vosk-model-small-en-us-0.15.zip
python -c "import vosk, speech_recognition, pyaudio; print('OK')"
3.2 Проверка работоспособности. Выполните команды:
ls vosk-model-small-en-us-0.15
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Скрипты запускаются в активированном окружении: python voice.py.

4. Описание операций
4.1 Операция 1. Загрузка модели распознавания
Условия выполнения: Установлен Vosk.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Скачайте модель нужного языка с сайта alphacephei.com/vosk/models.
2. Распакуйте её в каталог проекта.
Результат: модель готова к использованию.

4.2 Операция 2. Распознавание речи с микрофона
Условия выполнения: Модель загружена, микрофон подключён.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Создайте объект Model и KaldiRecognizer.
2. Запустите потоковое чтение с микрофона и передайте данные в распознаватель.
3. Выведите результат.
Результат: речь преобразована в текст.

4.3 Операция 3. Выполнение команды голосом
Условия выполнения: Распознавание работает.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Сравните распознанный текст со списком команд.
2. Выполните соответствующее действие.
Результат: команда выполнена.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Не устанавливается PyAudio: установите заголовки sudo apt install portaudio19-dev. Плохое распознавание: проверьте уровень микрофона и выберите модель нужного языка.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Используйте короткий набор фраз-команд для повышения точности. Для обработки данных не отправляйте записи речи в облако без согласия пользователя. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
