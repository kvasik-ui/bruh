Руководство оператора: Vosk (офлайн распознавание речи)
Вариант задания № 22. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Распознавание речи без подключения к интернету для голосового управления приложением.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; Python 3.10 и новее; микрофон; PortAudio.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install portaudio19-dev ffmpeg python3-pip python3-venv -y
python3 -m venv ~/voice-env && source ~/voice-env/bin/activate
pip install vosk SpeechRecognition pyaudio
wget https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip
unzip vosk-model-small-en-us-0.15.zip
python -c "import vosk, speech_recognition, pyaudio; print('OK')"
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Скрипты запускаются в активированном окружении: python voice.py.

3.3 Проверка работоспособности. Выполните команды:
ls vosk-model-small-en-us-0.15
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Загрузка модели распознавания. Условия: установлен Vosk.
   1. Скачайте модель нужного языка с сайта alphacephei.com/vosk/models.
   2. Распакуйте её в каталог проекта.
   Результат: модель готова к использованию.
3.4.2 Распознавание речи с микрофона. Условия: модель загружена, микрофон подключён.
   1. Создайте объект Model и KaldiRecognizer.
   2. Запустите потоковое чтение с микрофона и передайте данные в распознаватель.
   3. Выведите результат.
   Результат: речь преобразована в текст.
3.4.3 Выполнение команды голосом. Условия: распознавание работает.
   1. Сравните распознанный текст со списком команд.
   2. Выполните соответствующее действие.
   Результат: команда выполнена.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Не устанавливается PyAudio: установите заголовки sudo apt install portaudio19-dev.
– Плохое распознавание: проверьте уровень микрофона и выберите модель нужного языка.
