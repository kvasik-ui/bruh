Руководство оператора: FreeCAD (параметрическое моделирование)
Вариант задания № 21. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Создание трёхмерных моделей с параметрическими зависимостями для систем автоматизированного проектирования.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; ОЗУ не менее 8 ГБ; видеокарта с поддержкой OpenGL 3.3.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install qtcreator g++ cmake -y
sudo apt install libocct-foundation-dev libocct-data-exchange-dev -y
sudo apt install flatpak -y
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak install flathub org.freecadweb.FreeCAD -y
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Запустите FreeCAD из меню приложений или командой freecad.

3.3 Проверка работоспособности. Выполните команды:
flatpak run org.freecadweb.FreeCAD --version
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Создание эскиза. Условия: FreeCAD запущен, создан документ.
   1. Откройте верстак Sketcher.
   2. Нарисуйте профиль и задайте размеры.
   Результат: эскиз создан и полностью ограничен.
3.4.2 Создание детали. Условия: эскиз создан.
   1. Выберите инструмент Pad (выдавливание).
   2. Задайте высоту и подтвердите.
   Результат: деталь создана.
3.4.3 Изменение параметра. Условия: деталь создана.
   1. Измените размер в эскизе или в таблице параметров.
   2. Убедитесь, что модель перестроилась.
   Результат: модель обновлена по параметру.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Программа зависает при пересчёте: упростите модель или уменьшите число зависимостей.
– Ошибка открытия файла: проверьте версию FreeCAD и сохраните файл заново.
