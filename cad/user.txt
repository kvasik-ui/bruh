Руководство пользователя: FreeCAD (параметрическое моделирование)

1. Введение
1.1 Область применения. Создание трёхмерных моделей с параметрическими зависимостями для систем автоматизированного проектирования.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Создание трёхмерных моделей с параметрическими зависимостями для систем автоматизированного проектирования. Условия применения: Ubuntu 26.04 LTS; ОЗУ не менее 8 ГБ; видеокарта с поддержкой OpenGL 3.3.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install qtcreator g++ cmake -y
sudo apt install libocct-foundation-dev libocct-data-exchange-dev -y
sudo apt install flatpak -y
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak install flathub org.freecadweb.FreeCAD -y
3.2 Проверка работоспособности. Выполните команды:
flatpak run org.freecadweb.FreeCAD --version
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Запустите FreeCAD из меню приложений или командой freecad.

4. Описание операций
4.1 Операция 1. Создание эскиза
Условия выполнения: FreeCAD запущен, создан документ.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте верстак Sketcher.
2. Нарисуйте профиль и задайте размеры.
Результат: эскиз создан и полностью ограничен.

4.2 Операция 2. Создание детали
Условия выполнения: Эскиз создан.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выберите инструмент Pad (выдавливание).
2. Задайте высоту и подтвердите.
Результат: деталь создана.

4.3 Операция 3. Изменение параметра
Условия выполнения: Деталь создана.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Измените размер в эскизе или в таблице параметров.
2. Убедитесь, что модель перестроилась.
Результат: модель обновлена по параметру.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Программа зависает при пересчёте: упростите модель или уменьшите число зависимостей. Ошибка открытия файла: проверьте версию FreeCAD и сохраните файл заново.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Называйте объекты и параметры понятными именами. Сохраняйте резервные копии файлов моделей. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
