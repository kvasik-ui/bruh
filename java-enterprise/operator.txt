Руководство оператора: Apache Tomcat 10 (сервер приложений)
Вариант задания № 5. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Локальное развёртывание и тестирование Java-приложений (Servlet, JSP, Spring-приложения в WAR-архиве).

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; OpenJDK 21; ОЗУ не менее 4 ГБ.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo snap install intellij-idea-community --classic
sudo apt install openjdk-21-jdk -y
sudo apt install tomcat10 -y
sudo systemctl enable --now tomcat10
sudo apt install maven -y
mvn -q archetype:generate -DgroupId=ru.test -DartifactId=bank-app -DarchetypeArtifactId=maven-archetype-webapp -DinteractiveMode=false
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Служба Tomcat стартует автоматически; проверка в браузере: http://localhost:8080.

3.3 Проверка работоспособности. Выполните команды:
sudo aa-status
java -version && mvn -version
curl -I http://localhost:8080
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Развёртывание WAR-приложения. Условия: собран файл приложения .war; служба Tomcat запущена.
   1. Скопируйте файл в каталог: sudo cp app.war /var/lib/tomcat10/webapps/.
   2. Подождите появления каталога приложения в webapps.
   3. Откройте http://localhost:8080/app в браузере.
   Результат: приложение доступно в браузере.
3.4.2 Просмотр журналов сервера. Условия: служба Tomcat запущена.
   1. Выполните sudo tail -n 50 /var/log/tomcat10/catalina.out.
   2. Найдите строки с ошибками (SEVERE, Exception).
   Результат: ошибки развёртывания выявлены.
3.4.3 Перезапуск службы. Условия: служба Tomcat запущена.
   1. Выполните sudo systemctl restart tomcat10.
   2. Проверьте статус командой sudo systemctl status tomcat10.
   Результат: служба работает после перезапуска.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Порт 8080 занят: найдите процесс командой sudo ss -ltnp | grep 8080.
– Ошибка доступа к webapps: проверьте владельца каталога (tomcat).
