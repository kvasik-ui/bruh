Руководство пользователя: Apache Tomcat 10 (сервер приложений)

1. Введение
1.1 Область применения. Локальное развёртывание и тестирование Java-приложений (Servlet, JSP, Spring-приложения в WAR-архиве).
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Локальное развёртывание и тестирование Java-приложений (Servlet, JSP, Spring-приложения в WAR-архиве). Условия применения: Ubuntu 26.04 LTS; OpenJDK 21; ОЗУ не менее 4 ГБ.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install intellij-idea-community --classic
sudo apt install openjdk-21-jdk -y
sudo apt install tomcat10 -y
sudo systemctl enable --now tomcat10
sudo apt install maven -y
mvn -q archetype:generate -DgroupId=ru.test -DartifactId=bank-app -DarchetypeArtifactId=maven-archetype-webapp -DinteractiveMode=false
3.2 Проверка работоспособности. Выполните команды:
sudo aa-status
java -version && mvn -version
curl -I http://localhost:8080
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Служба Tomcat стартует автоматически; проверка в браузере: http://localhost:8080.

4. Описание операций
4.1 Операция 1. Развёртывание WAR-приложения
Условия выполнения: Собран файл приложения .war; служба Tomcat запущена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Скопируйте файл в каталог: sudo cp app.war /var/lib/tomcat10/webapps/.
2. Подождите появления каталога приложения в webapps.
3. Откройте http://localhost:8080/app в браузере.
Результат: приложение доступно в браузере.

4.2 Операция 2. Просмотр журналов сервера
Условия выполнения: Служба Tomcat запущена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните sudo tail -n 50 /var/log/tomcat10/catalina.out.
2. Найдите строки с ошибками (SEVERE, Exception).
Результат: ошибки развёртывания выявлены.

4.3 Операция 3. Перезапуск службы
Условия выполнения: Служба Tomcat запущена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните sudo systemctl restart tomcat10.
2. Проверьте статус командой sudo systemctl status tomcat10.
Результат: служба работает после перезапуска.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Порт 8080 занят: найдите процесс командой sudo ss -ltnp | grep 8080. Ошибка доступа к webapps: проверьте владельца каталога (tomcat).
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Не используйте учётную запись администратора Tomcat по умолчанию. Отключайте менеджер приложений на рабочих серверах. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
