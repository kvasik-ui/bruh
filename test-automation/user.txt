Руководство пользователя: Allure (отчёты о тестировании)

1. Введение
1.1 Область применения. Формирование наглядных отчётов по результатам автоматизированных тестов Python, Java и JavaScript.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Формирование наглядных отчётов по результатам автоматизированных тестов Python, Java и JavaScript. Условия применения: Ubuntu 26.04 LTS; Python 3.10 и новее; Java 21; Node.js LTS.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install pycharm-community --classic
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/test-env && source ~/test-env/bin/activate
pip install pytest selenium allure-pytest locust
sudo snap install chromium
sudo apt install openjdk-21-jdk nodejs npm -y
sudo npm install -g allure-commandline
sudo apt install jmeter -y
3.2 Проверка работоспособности. Выполните команды:
pytest --version && locust --version
allure --version
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Тесты запускаются командой pytest --alluredir=allure-results; отчёт открывается командой allure serve allure-results.

4. Описание операций
4.1 Операция 1. Запуск тестов с сохранением результатов
Условия выполнения: Окружение активировано, pytest установлен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Перейдите в каталог с тестами.
2. Выполните pytest --alluredir=allure-results.
Результат: результаты сохранены в каталоге allure-results.

4.2 Операция 2. Просмотр отчёта
Условия выполнения: Результаты тестов сохранены.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните allure serve allure-results.
2. Откройте адрес, который выведет команда, в браузере.
Результат: отчёт открыт в браузере.

4.3 Операция 3. Экспорт отчёта
Условия выполнения: Отчёт сформирован.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните allure generate allure-results -o report --clean.
2. Откройте файл report/index.html.
Результат: статический отчёт готов к передаче.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Команда allure не найдена: проверьте установку npm и путь к глобальным пакетам. Пустой отчёт: убедитесь, что в pytest указан --alluredir.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Добавляйте в тесты понятные названия и описания шагов. Храните отчёты вне репозитория кода. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
