Руководство пользователя: OpenXR (стандарт для AR/VR-шлемов)

1. Введение
1.1 Область применения. Единый программный интерфейс для работы приложений дополненной и виртуальной реальности с AR/VR-шлемами.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Единый программный интерфейс для работы приложений дополненной и виртуальной реальности с AR/VR-шлемами. Условия применения: Ubuntu 26.04 LTS; совместимая видеокарта и драйвер; .NET SDK 8 для C#.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
mkdir -p ~/godot && cd ~/godot
sudo apt install dotnet-sdk-8.0 -y
apt search openxr
sudo apt install libopenxr-loader1 -y
sudo apt install blender -y
3.2 Проверка работоспособности. Выполните команды:
dotnet --version && apt list --installed | grep openxr
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Запустите редактор Godot 4 .NET из распакованного каталога, включите поддержку OpenXR в настройках проекта.

4. Описание операций
4.1 Операция 1. Включение OpenXR в проекте
Условия выполнения: Установлен Godot и загрузчик OpenXR.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте настройки проекта (Project Settings).
2. В разделе XR включите OpenXR.
3. Сохраните проект.
Результат: проект готов к работе с OpenXR.

4.2 Операция 2. Подключение шлема
Условия выполнения: Шлем подключён и настроен в системе.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Запустите проект в режиме XR.
2. Проверьте отображение сцены в шлеме.
Результат: сцена отображается в шлеме.

4.3 Операция 3. Проверка загрузчика
Условия выполнения: Загрузчик OpenXR установлен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните apt list --installed | grep openxr.
2. Убедитесь, что пакет присутствует в списке.
Результат: загрузчик установлен.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Шлем не виден: проверьте подключение и правила доступа (udev) для устройства. Ошибка загрузчика: переустановите пакет командой sudo apt install --reinstall libopenxr-loader1.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Тестируйте приложение на реальном шлеме, а не только в эмуляторе. Учитывайте требования шлема к частоте кадров. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
