Руководство оператора: OpenXR (стандарт для AR/VR-шлемов)
Вариант задания № 12. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Единый программный интерфейс для работы приложений дополненной и виртуальной реальности с AR/VR-шлемами.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; совместимая видеокарта и драйвер; .NET SDK 8 для C#.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
mkdir -p ~/godot && cd ~/godot
sudo apt install dotnet-sdk-8.0 -y
apt search openxr
sudo apt install libopenxr-loader1 -y
sudo apt install blender -y
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Запустите редактор Godot 4 .NET из распакованного каталога, включите поддержку OpenXR в настройках проекта.

3.3 Проверка работоспособности. Выполните команды:
dotnet --version && apt list --installed | grep openxr
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Включение OpenXR в проекте. Условия: установлен Godot и загрузчик OpenXR.
   1. Откройте настройки проекта (Project Settings).
   2. В разделе XR включите OpenXR.
   3. Сохраните проект.
   Результат: проект готов к работе с OpenXR.
3.4.2 Подключение шлема. Условия: шлем подключён и настроен в системе.
   1. Запустите проект в режиме XR.
   2. Проверьте отображение сцены в шлеме.
   Результат: сцена отображается в шлеме.
3.4.3 Проверка загрузчика. Условия: загрузчик OpenXR установлен.
   1. Выполните apt list --installed | grep openxr.
   2. Убедитесь, что пакет присутствует в списке.
   Результат: загрузчик установлен.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Шлем не виден: проверьте подключение и правила доступа (udev) для устройства.
– Ошибка загрузчика: переустановите пакет командой sudo apt install --reinstall libopenxr-loader1.
