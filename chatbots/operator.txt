Руководство оператора: Rasa (фреймворк диалоговых систем)
Вариант задания № 26. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Создание чат-ботов и виртуальных помощников с распознаванием намерений и управлением диалогом.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; Python 3.10 (рекомендуется для Rasa); ОЗУ не менее 8 ГБ.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install python3.10 python3.10-venv -y || (pip install uv && uv python install 3.10)
python3.10 -m venv ~/bot-env && source ~/bot-env/bin/activate
pip install rasa
pip install spacy nltk
pip install jupyterlab
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Создайте проект командой rasa init, обучите модель командой rasa train.

3.3 Проверка работоспособности. Выполните команды:
rasa --version
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Создание проекта бота. Условия: окружение активно, Rasa установлена.
   1. Выполните rasa init в пустом каталоге.
   2. Ответьте на вопросы мастера (например, на обучение модели сразу).
   Результат: проект бота создан.
3.4.2 Обучение модели. Условия: проект создан.
   1. Выполните rasa train.
   2. Дождитесь окончания обучения и сохранения модели в каталоге models.
   Результат: модель обучена.
3.4.3 Запуск и проверка диалога. Условия: модель обучена.
   1. Запустите сервер командой rasa shell.
   2. Введите тестовые сообщения и проверьте ответы.
   Результат: бот отвечает по сценарию.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Ошибка обучения из-за нехватки памяти: уменьшите число эпох в config.yml.
– Бот не распознаёт намерения: добавьте примеры фраз в файл nlu.yml и обучите модель заново.
