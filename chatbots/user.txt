Руководство пользователя: Rasa (фреймворк диалоговых систем)

1. Введение
1.1 Область применения. Создание чат-ботов и виртуальных помощников с распознаванием намерений и управлением диалогом.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Создание чат-ботов и виртуальных помощников с распознаванием намерений и управлением диалогом. Условия применения: Ubuntu 26.04 LTS; Python 3.10 (рекомендуется для Rasa); ОЗУ не менее 8 ГБ.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install python3.10 python3.10-venv -y || (pip install uv && uv python install 3.10)
python3.10 -m venv ~/bot-env && source ~/bot-env/bin/activate
pip install rasa
pip install spacy nltk
pip install jupyterlab
3.2 Проверка работоспособности. Выполните команды:
rasa --version
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Создайте проект командой rasa init, обучите модель командой rasa train.

4. Описание операций
4.1 Операция 1. Создание проекта бота
Условия выполнения: Окружение активно, Rasa установлена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните rasa init в пустом каталоге.
2. Ответьте на вопросы мастера (например, на обучение модели сразу).
Результат: проект бота создан.

4.2 Операция 2. Обучение модели
Условия выполнения: Проект создан.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните rasa train.
2. Дождитесь окончания обучения и сохранения модели в каталоге models.
Результат: модель обучена.

4.3 Операция 3. Запуск и проверка диалога
Условия выполнения: Модель обучена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Запустите сервер командой rasa shell.
2. Введите тестовые сообщения и проверьте ответы.
Результат: бот отвечает по сценарию.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Ошибка обучения из-за нехватки памяти: уменьшите число эпох в config.yml. Бот не распознаёт намерения: добавьте примеры фраз в файл nlu.yml и обучите модель заново.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Пополняйте обучающие примеры на основе реальных диалогов. Проверяйте модель командой rasa test. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
