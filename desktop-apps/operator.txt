Руководство оператора: electron-builder (создание установочных пакетов)
Вариант задания № 6. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Сборка исполняемых файлов и установочных пакетов (.deb, AppImage, .rpm) для Windows, macOS и Linux из кода Electron-приложения.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; Node.js LTS; утилиты fakeroot, dpkg-dev, rpm.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo snap install code --classic
sudo apt install nodejs npm -y
mkdir ~/desktop-app && cd ~/desktop-app && npm init -y
npm install --save-dev electron electron-builder
npm pkg set main=main.js
sudo apt install fakeroot dpkg-dev rpm -y
npx electron-builder --linux deb
sudo apt install keepassxc -y
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Сборка выполняется командой npx electron-builder в каталоге проекта.

3.3 Проверка работоспособности. Выполните команды:
cat > main.js <<'EOF'
node --version && npx electron --version
ls dist/*.deb
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Настройка сборки в package.json. Условия: проект Electron создан, зависимости установлены.
   1. Откройте package.json и добавьте раздел build с именем приложения.
   2. Укажите цели сборки, например linux с типами deb и AppImage.
   3. Сохраните файл.
   Результат: конфигурация сборки готова.
3.4.2 Сборка установочного пакета. Условия: настройка сборки выполнена.
   1. Выполните npx electron-builder --linux.
   2. Дождитесь окончания сборки.
   3. Найдите результат в каталоге dist/.
   Результат: установочный пакет создан в каталоге dist.
3.4.3 Проверка установки пакета. Условия: пакет .deb создан.
   1. Выполните sudo dpkg -i dist/имя-пакета.deb.
   2. Запустите приложение из меню или командой.
   Результат: приложение установлено и запускается.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Ошибка сборки из-за отсутствия fakeroot: установите пакет командой sudo apt install fakeroot.
– Неполные зависимости пакета: выполните sudo apt -f install.
