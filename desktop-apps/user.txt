Руководство пользователя: electron-builder (создание установочных пакетов)

1. Введение
1.1 Область применения. Сборка исполняемых файлов и установочных пакетов (.deb, AppImage, .rpm) для Windows, macOS и Linux из кода Electron-приложения.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Сборка исполняемых файлов и установочных пакетов (.deb, AppImage, .rpm) для Windows, macOS и Linux из кода Electron-приложения. Условия применения: Ubuntu 26.04 LTS; Node.js LTS; утилиты fakeroot, dpkg-dev, rpm.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install code --classic
sudo apt install nodejs npm -y
mkdir ~/desktop-app && cd ~/desktop-app && npm init -y
npm install --save-dev electron electron-builder
npm pkg set main=main.js
sudo apt install fakeroot dpkg-dev rpm -y
npx electron-builder --linux deb
sudo apt install keepassxc -y
3.2 Проверка работоспособности. Выполните команды:
cat > main.js <<'EOF'
node --version && npx electron --version
ls dist/*.deb
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Сборка выполняется командой npx electron-builder в каталоге проекта.

4. Описание операций
4.1 Операция 1. Настройка сборки в package.json
Условия выполнения: Проект Electron создан, зависимости установлены.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте package.json и добавьте раздел build с именем приложения.
2. Укажите цели сборки, например linux с типами deb и AppImage.
3. Сохраните файл.
Результат: конфигурация сборки готова.

4.2 Операция 2. Сборка установочного пакета
Условия выполнения: Настройка сборки выполнена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните npx electron-builder --linux.
2. Дождитесь окончания сборки.
3. Найдите результат в каталоге dist/.
Результат: установочный пакет создан в каталоге dist.

4.3 Операция 3. Проверка установки пакета
Условия выполнения: Пакет .deb создан.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните sudo dpkg -i dist/имя-пакета.deb.
2. Запустите приложение из меню или командой.
Результат: приложение установлено и запускается.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Ошибка сборки из-за отсутствия fakeroot: установите пакет командой sudo apt install fakeroot. Неполные зависимости пакета: выполните sudo apt -f install.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Подписывайте установочные пакеты перед публикацией. Указывайте версию приложения в package.json для каждой сборки. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
