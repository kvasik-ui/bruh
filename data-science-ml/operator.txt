Руководство оператора: DVC (версии данных и моделей)
Вариант задания № 7. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Версионирование наборов данных и моделей машинного обучения вместе с кодом в Git.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; Python 3.10 и новее; Git.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/ml-env && source ~/ml-env/bin/activate
pip install jupyterlab
pip install numpy pandas scikit-learn matplotlib torch
pip install mlflow dvc
sudo apt install r-base -y
ubuntu-drivers devices
sudo ubuntu-drivers install
sudo apt install nvidia-cuda-toolkit -y
sudo apt install cryptsetup -y
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Команды DVC выполняются в терминале в каталоге проекта (после активации окружения).

3.3 Проверка работоспособности. Выполните команды:
nvidia-smi
cryptsetup --version
dvc --version
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Инициализация репозитория данных. Условия: проект находится в Git-репозитории; установлен DVC.
   1. Выполните dvc init в каталоге проекта.
   2. Зафиксируйте служебные файлы: git add .dvc .dvcignore && git commit -m "DVC init".
   Результат: DVC инициализирован.
3.4.2 Добавление набора данных. Условия: DVC инициализирован.
   1. Выполните dvc add data/dataset.csv.
   2. Добавьте файл dataset.csv.dvc в Git: git add data/dataset.csv.dvc data/.gitignore.
   3. Зафиксируйте изменения командой git commit.
   Результат: версия набора данных зафиксирована.
3.4.3 Возврат к предыдущей версии данных. Условия: есть несколько зафиксированных версий.
   1. Выберите нужный коммит командой git log.
   2. Вернитесь к нему командой git checkout <коммит> -- data/dataset.csv.dvc.
   3. Восстановите данные командой dvc checkout.
   Результат: набор данных возвращён к выбранной версии.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Данные недоступны после клонирования: выполните dvc pull (нужно настроить удалённое хранилище).
– Конфликт версий: не редактируйте файлы .dvc вручную, используйте dvc add повторно.
