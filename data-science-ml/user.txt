Руководство пользователя: DVC (версии данных и моделей)

1. Введение
1.1 Область применения. Версионирование наборов данных и моделей машинного обучения вместе с кодом в Git.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Версионирование наборов данных и моделей машинного обучения вместе с кодом в Git. Условия применения: Ubuntu 26.04 LTS; Python 3.10 и новее; Git.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/ml-env && source ~/ml-env/bin/activate
pip install jupyterlab
pip install numpy pandas scikit-learn matplotlib torch
pip install mlflow dvc
sudo apt install r-base -y
ubuntu-drivers devices
sudo ubuntu-drivers install
sudo apt install nvidia-cuda-toolkit -y
sudo apt install cryptsetup -y
3.2 Проверка работоспособности. Выполните команды:
nvidia-smi
cryptsetup --version
dvc --version
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Команды DVC выполняются в терминале в каталоге проекта (после активации окружения).

4. Описание операций
4.1 Операция 1. Инициализация репозитория данных
Условия выполнения: Проект находится в Git-репозитории; установлен DVC.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните dvc init в каталоге проекта.
2. Зафиксируйте служебные файлы: git add .dvc .dvcignore && git commit -m "DVC init".
Результат: DVC инициализирован.

4.2 Операция 2. Добавление набора данных
Условия выполнения: DVC инициализирован.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните dvc add data/dataset.csv.
2. Добавьте файл dataset.csv.dvc в Git: git add data/dataset.csv.dvc data/.gitignore.
3. Зафиксируйте изменения командой git commit.
Результат: версия набора данных зафиксирована.

4.3 Операция 3. Возврат к предыдущей версии данных
Условия выполнения: Есть несколько зафиксированных версий.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выберите нужный коммит командой git log.
2. Вернитесь к нему командой git checkout <коммит> -- data/dataset.csv.dvc.
3. Восстановите данные командой dvc checkout.
Результат: набор данных возвращён к выбранной версии.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Данные недоступны после клонирования: выполните dvc pull (нужно настроить удалённое хранилище). Конфликт версий: не редактируйте файлы .dvc вручную, используйте dvc add повторно.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Настройте удалённое хранилище (dvc remote add). Не добавляйте в Git большие файлы данных напрямую. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
