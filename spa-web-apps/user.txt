Руководство пользователя: Vite (сборщик фронтенд-приложений)

1. Введение
1.1 Область применения. Сборка и оптимизация SPA-приложений на React, Vue или Angular, локальный сервер разработки.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Сборка и оптимизация SPA-приложений на React, Vue или Angular, локальный сервер разработки. Условия применения: Ubuntu 26.04 LTS; Node.js LTS 22; npm.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install webstorm --classic
sudo apt install nodejs npm -y
sudo npm install -g vite eslint prettier
npm create vite@latest my-spa -- --template react
sudo apt install docker.io -y
sudo systemctl enable --now docker
sudo docker run -d --name mongo -p 127.0.0.1:27017:27017 -e MONGO_INITDB_ROOT_USERNAME=admin -e 'MONGO_INITDB_ROOT_PASSWORD=ChangeMe_Strong1!' mongo:7
3.2 Проверка работоспособности. Выполните команды:
node --version && vite --version
sudo docker ps --filter name=mongo
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Создайте проект: npm create vite@latest my-app, затем перейдите в каталог и выполните npm run dev.

4. Описание операций
4.1 Операция 1. Создание проекта
Условия выполнения: Установлены Node.js и Vite.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните npm create vite@latest my-app.
2. Выберите шаблон (например, React или Vue).
3. Перейдите в каталог и выполните npm install.
Результат: проект создан и готов к запуску.

4.2 Операция 2. Запуск сервера разработки
Условия выполнения: Зависимости установлены.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните npm run dev.
2. Откройте адрес http://localhost:5173 в браузере.
Результат: приложение отображается в браузере.

4.3 Операция 3. Сборка продукционной версии
Условия выполнения: Проект готов.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните npm run build.
2. Проверьте каталог dist/ с готовыми файлами.
3. Для проверки результата выполните npm run preview.
Результат: сборка выполнена без ошибок.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Порт 5173 занят: Vite выберет другой порт, его видно в выводе команды. Ошибки зависимостей: удалите node_modules и выполните npm install заново.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Используйте ESLint и Prettier для проверки кода перед сборкой. Регулярно проверяйте зависимости командой npm audit. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
