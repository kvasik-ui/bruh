Руководство оператора: Vite (сборщик фронтенд-приложений)
Вариант задания № 8. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Сборка и оптимизация SPA-приложений на React, Vue или Angular, локальный сервер разработки.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; Node.js LTS 22; npm.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo snap install webstorm --classic
sudo apt install nodejs npm -y
sudo npm install -g vite eslint prettier
npm create vite@latest my-spa -- --template react
sudo apt install docker.io -y
sudo systemctl enable --now docker
sudo docker run -d --name mongo -p 127.0.0.1:27017:27017 -e MONGO_INITDB_ROOT_USERNAME=admin -e 'MONGO_INITDB_ROOT_PASSWORD=ChangeMe_Strong1!' mongo:7
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Создайте проект: npm create vite@latest my-app, затем перейдите в каталог и выполните npm run dev.

3.3 Проверка работоспособности. Выполните команды:
node --version && vite --version
sudo docker ps --filter name=mongo
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Создание проекта. Условия: установлены Node.js и Vite.
   1. Выполните npm create vite@latest my-app.
   2. Выберите шаблон (например, React или Vue).
   3. Перейдите в каталог и выполните npm install.
   Результат: проект создан и готов к запуску.
3.4.2 Запуск сервера разработки. Условия: зависимости установлены.
   1. Выполните npm run dev.
   2. Откройте адрес http://localhost:5173 в браузере.
   Результат: приложение отображается в браузере.
3.4.3 Сборка продукционной версии. Условия: проект готов.
   1. Выполните npm run build.
   2. Проверьте каталог dist/ с готовыми файлами.
   3. Для проверки результата выполните npm run preview.
   Результат: сборка выполнена без ошибок.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Порт 5173 занят: Vite выберет другой порт, его видно в выводе команды.
– Ошибки зависимостей: удалите node_modules и выполните npm install заново.
