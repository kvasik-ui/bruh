Руководство оператора: Grafana (визуализация энергосетей)
Вариант задания № 27. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Отображение телеметрии энергосетей (напряжение, ток, мощность) на панелях мониторинга в реальном времени.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; Docker; ОЗУ не менее 4 ГБ; libiec61850 и OpenDNP3 для источников данных.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install qtcreator g++ cmake libssl-dev git -y
git clone https://github.com/mz-automation/libiec61850.git
cmake .. && make -j$(nproc)
git clone --recursive https://github.com/dnp3/opendnp3.git
sudo apt install docker.io -y
sudo systemctl enable --now docker
sudo docker run -d --name grafana -p 127.0.0.1:3000:3000 grafana/grafana
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Откройте в браузере http://localhost:3000; вход по умолчанию admin/admin с обязательной сменой пароля.

3.3 Проверка работоспособности. Выполните команды:
curl -I http://localhost:3000
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Первый вход и смена пароля. Условия: контейнер Grafana запущен.
   1. Откройте http://localhost:3000 и войдите как admin/admin.
   2. Задайте новый пароль.
   Результат: пароль администратора изменён.
3.4.2 Добавление источника данных. Условия: Grafana доступна.
   1. Откройте Connections → Data sources → Add data source.
   2. Выберите тип источника (например, Prometheus или InfluxDB) и укажите адрес.
   3. Нажмите Save & test.
   Результат: источник данных подключён.
3.4.3 Создание панели мониторинга. Условия: источник данных подключён.
   1. Создайте новую панель (New dashboard → Add visualization).
   2. Выберите источник и запрос к телеметрии.
   3. Сохраните панель.
   Результат: панель отображает данные сети.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Контейнер не запускается: проверьте docker logs grafana.
– Источник данных недоступен: проверьте адрес и сетевой доступ от контейнера.
