Руководство пользователя: Grafana (визуализация энергосетей)

1. Введение
1.1 Область применения. Отображение телеметрии энергосетей (напряжение, ток, мощность) на панелях мониторинга в реальном времени.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Отображение телеметрии энергосетей (напряжение, ток, мощность) на панелях мониторинга в реальном времени. Условия применения: Ubuntu 26.04 LTS; Docker; ОЗУ не менее 4 ГБ; libiec61850 и OpenDNP3 для источников данных.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install qtcreator g++ cmake libssl-dev git -y
git clone https://github.com/mz-automation/libiec61850.git
cmake .. && make -j$(nproc)
git clone --recursive https://github.com/dnp3/opendnp3.git
sudo apt install docker.io -y
sudo systemctl enable --now docker
sudo docker run -d --name grafana -p 127.0.0.1:3000:3000 grafana/grafana
3.2 Проверка работоспособности. Выполните команды:
curl -I http://localhost:3000
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Откройте в браузере http://localhost:3000; вход по умолчанию admin/admin с обязательной сменой пароля.

4. Описание операций
4.1 Операция 1. Первый вход и смена пароля
Условия выполнения: Контейнер Grafana запущен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте http://localhost:3000 и войдите как admin/admin.
2. Задайте новый пароль.
Результат: пароль администратора изменён.

4.2 Операция 2. Добавление источника данных
Условия выполнения: Grafana доступна.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте Connections → Data sources → Add data source.
2. Выберите тип источника (например, Prometheus или InfluxDB) и укажите адрес.
3. Нажмите Save & test.
Результат: источник данных подключён.

4.3 Операция 3. Создание панели мониторинга
Условия выполнения: Источник данных подключён.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Создайте новую панель (New dashboard → Add visualization).
2. Выберите источник и запрос к телеметрии.
3. Сохраните панель.
Результат: панель отображает данные сети.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Контейнер не запускается: проверьте docker logs grafana. Источник данных недоступен: проверьте адрес и сетевой доступ от контейнера.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Ограничьте доступ к Grafana по ролям. Настройте оповещения о выходе параметров за допустимые пределы. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
