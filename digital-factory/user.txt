Руководство пользователя: OPC UA SDK (OPCFoundation.NetStandard.Opc.Ua) для SCADA-систем

1. Введение
1.1 Область применения. Чтение и запись данных промышленного оборудования по протоколу OPC UA из приложений на C#.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Чтение и запись данных промышленного оборудования по протоколу OPC UA из приложений на C#. Условия применения: Ubuntu 26.04 LTS; .NET SDK 8; IDE JetBrains Rider.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install rider --classic
sudo apt install dotnet-sdk-8.0 -y
dotnet new console -n FactoryOPC && cd FactoryOPC
dotnet add package OPCFoundation.NetStandard.Opc.Ua
dotnet build
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/opcua-env && source ~/opcua-env/bin/activate
pip install asyncua
sudo apt install mosquitto mosquitto-clients -y
sudo systemctl enable --now mosquitto
3.2 Проверка работоспособности. Выполните команды:
dotnet build
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Откройте Rider из меню приложений, создайте проект командой dotnet new console -n FactoryOPC.

4. Описание операций
4.1 Операция 1. Подключение к серверу OPC UA
Условия выполнения: Известен адрес сервера OPC UA.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Подключите пакет командой dotnet add package OPCFoundation.NetStandard.Opc.Ua.
2. Создайте сессию с адресом сервера opc.tcp://адрес:порт.
3. Выполните сборку командой dotnet build.
Результат: сессия с сервером установлена.

4.2 Операция 2. Чтение значения тега
Условия выполнения: Сессия установлена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Укажите идентификатор узла (NodeId) нужного тега.
2. Выполните чтение значения и вывод в консоль.
Результат: значение тега получено.

4.3 Операция 3. Публикация телеметрии в MQTT
Условия выполнения: Брокер Mosquitto запущен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Отправьте значение тега командой mosquitto_pub или из приложения.
2. Проверьте получение подписчиком командой mosquitto_sub.
Результат: телеметрия передана.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Сервер OPC UA недоступен: проверьте сеть и порт сервера. Ошибка сертификата: доверьте сертификат клиента на стороне сервера.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Используйте защищённый режим OPC UA с подписью и шифрованием. Ограничьте права записи в промышленные теги. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
