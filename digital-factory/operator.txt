Руководство оператора: OPC UA SDK (OPCFoundation.NetStandard.Opc.Ua) для SCADA-систем
Вариант задания № 25. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Чтение и запись данных промышленного оборудования по протоколу OPC UA из приложений на C#.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; .NET SDK 8; IDE JetBrains Rider.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo snap install rider --classic
sudo apt install dotnet-sdk-8.0 -y
dotnet new console -n FactoryOPC && cd FactoryOPC
dotnet add package OPCFoundation.NetStandard.Opc.Ua
dotnet build
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/opcua-env && source ~/opcua-env/bin/activate
pip install asyncua
sudo apt install mosquitto mosquitto-clients -y
sudo systemctl enable --now mosquitto
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Откройте Rider из меню приложений, создайте проект командой dotnet new console -n FactoryOPC.

3.3 Проверка работоспособности. Выполните команды:
dotnet build
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Подключение к серверу OPC UA. Условия: известен адрес сервера OPC UA.
   1. Подключите пакет командой dotnet add package OPCFoundation.NetStandard.Opc.Ua.
   2. Создайте сессию с адресом сервера opc.tcp://адрес:порт.
   3. Выполните сборку командой dotnet build.
   Результат: сессия с сервером установлена.
3.4.2 Чтение значения тега. Условия: сессия установлена.
   1. Укажите идентификатор узла (NodeId) нужного тега.
   2. Выполните чтение значения и вывод в консоль.
   Результат: значение тега получено.
3.4.3 Публикация телеметрии в MQTT. Условия: брокер Mosquitto запущен.
   1. Отправьте значение тега командой mosquitto_pub или из приложения.
   2. Проверьте получение подписчиком командой mosquitto_sub.
   Результат: телеметрия передана.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Сервер OPC UA недоступен: проверьте сеть и порт сервера.
– Ошибка сертификата: доверьте сертификат клиента на стороне сервера.
