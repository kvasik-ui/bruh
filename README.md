# bruh

Материалы к экзамену: общий блок настройки (`common.txt`) и папки по вариантам.
В каждой папке три файла: `user.txt` (руководство пользователя), `operator.txt` (руководство оператора), `code.txt` (код).

## Скачивание на Ubuntu

```bash
git clone https://github.com/<ВАШ_ЛОГИН>/bruh.git "$(xdg-user-dir DESKTOP)/bruh"
```

Папка появится на рабочем столе: `$(xdg-user-dir DESKTOP)/bruh`.

Перед использованием в `common.txt` вместо `<логин>:<пароль>` подставьте свои данные прокси.
