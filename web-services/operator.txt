Руководство оператора: Postman (тестирование API)
Вариант задания № 1. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Отправка HTTP-запросов к программным интерфейсам (REST API), проверка ответов сервера и автоматизация тестов.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 22.04 LTS и новее (проверено на 26.04 LTS), 64-разрядная; процессор x86-64 от 1 ГГц; ОЗУ не менее 4 ГБ; диск не менее 1 ГБ; snapd.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install snapd -y
sudo snap install postman
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Запустите командой postman или из меню приложений.

3.3 Проверка работоспособности. Выполните команды:
snap list postman
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Отправка GET-запроса. Условия: программа запущена, есть подключение к интернету.
   1. Нажмите New → HTTP Request.
   2. Выберите метод GET, введите адрес https://jsonplaceholder.typicode.com/posts/1.
   3. Нажмите Send и проверьте код 200 OK и тело ответа JSON.
   Результат: ответ получен и сохранён в истории запросов (History).
3.4.2 Отправка POST-запроса с телом JSON. Условия: программа запущена, есть подключение к интернету.
   1. Выберите метод POST, введите адрес https://jsonplaceholder.typicode.com/posts.
   2. Во вкладке Body выберите raw и JSON, введите тело запроса.
   3. Нажмите Send и проверьте код 201 Created.
   Результат: сервер вернул созданный объект.
3.4.3 Сохранение запроса в коллекцию. Условия: запрос отправлен, получен ответ.
   1. Нажмите Save, выберите New Collection, введите имя «API-тесты».
   2. Нажмите Save.
   Результат: запрос сохранён в коллекцию на боковой панели Collections.
3.4.4 Написание и запуск теста. Условия: запрос сохранён в коллекцию.
   1. Откройте вкладку Tests и введите код проверки статуса 200 (pm.response.to.have.status(200)).
   2. Нажмите Send и откройте Test Results.
   Результат: результат проверки Passed или Failed.
3.4.5 Экспорт коллекции в файл. Условия: коллекция создана.
   1. Откройте меню коллекции (…) и выберите Export.
   2. Выберите Collection v2.1 и сохраните файл .json.
   Результат: файл коллекции сохранён для резервной копии.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Could not get response: нет сети или файрвол блокирует запрос. Проверьте подключение (ping -c 3 google.com) и правила sudo ufw status.
– Ошибка SSL-сертификата: для тестовой среды можно отключить проверку в Settings; в боевой среде отключать нельзя.
– Программа не запускается после установки: выполните sudo snap remove postman и установите заново.
