Руководство пользователя: Restic (резервное копирование и восстановление)

1. Введение
1.1 Область применения. Создание зашифрованных резервных копий каталогов серверов и восстановление данных из них.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Создание зашифрованных резервных копий каталогов серверов и восстановление данных из них. Условия применения: Ubuntu 26.04 LTS; права sudo; место для резервных копий не менее объёма данных.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install ansible restic borgbackup -y
echo -e "[local]
localhost ansible_connection=local" > ~/inventory.ini
sudo apt install prometheus prometheus-node-exporter -y
sudo systemctl enable --now prometheus-node-exporter
sudo apt install qemu-system-x86 libvirt-daemon-system -y
sudo systemctl enable --now libvirtd
sudo usermod -aG libvirt $USER
curl -s http://localhost:9100/metrics | head -3
3.2 Проверка работоспособности. Выполните команды:
ansible -i ~/inventory.ini local -m ping
restic version && borg --version
sudo virsh list --all
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Restic работает командами в терминале.

4. Описание операций
4.1 Операция 1. Инициализация хранилища
Условия выполнения: Есть каталог для резервных копий.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните export RESTIC_PASSWORD=... (пароль хранилища).
2. Выполните restic init -r /backup/repo.
Результат: хранилище создано и зашифровано.

4.2 Операция 2. Создание резервной копии
Условия выполнения: Хранилище инициализировано.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните restic -r /backup/repo backup /home.
2. Проверьте вывод: количество файлов и размер.
Результат: резервная копия создана.

4.3 Операция 3. Восстановление данных
Условия выполнения: Есть хотя бы одна копия.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните restic -r /backup/repo snapshots и выберите нужный снимок.
2. Выполните restic -r /backup/repo restore latest --target /tmp/restore.
Результат: данные восстановлены в каталог /tmp/restore.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Пароль хранилища утерян: восстановление невозможно, поэтому храните пароль отдельно. Ошибка блокировки: удалите устаревшие блокировки командой restic unlock.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Делайте проверку копий: restic check. Храните копии в отдельном месте от исходных данных. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
