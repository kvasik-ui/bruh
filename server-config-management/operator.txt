Руководство оператора: Restic (резервное копирование и восстановление)
Вариант задания № 15. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Создание зашифрованных резервных копий каталогов серверов и восстановление данных из них.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; права sudo; место для резервных копий не менее объёма данных.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install ansible restic borgbackup -y
echo -e "[local]
localhost ansible_connection=local" > ~/inventory.ini
sudo apt install prometheus prometheus-node-exporter -y
sudo systemctl enable --now prometheus-node-exporter
sudo apt install qemu-system-x86 libvirt-daemon-system -y
sudo systemctl enable --now libvirtd
sudo usermod -aG libvirt $USER
curl -s http://localhost:9100/metrics | head -3
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Restic работает командами в терминале.

3.3 Проверка работоспособности. Выполните команды:
ansible -i ~/inventory.ini local -m ping
restic version && borg --version
sudo virsh list --all
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Инициализация хранилища. Условия: есть каталог для резервных копий.
   1. Выполните export RESTIC_PASSWORD=... (пароль хранилища).
   2. Выполните restic init -r /backup/repo.
   Результат: хранилище создано и зашифровано.
3.4.2 Создание резервной копии. Условия: хранилище инициализировано.
   1. Выполните restic -r /backup/repo backup /home.
   2. Проверьте вывод: количество файлов и размер.
   Результат: резервная копия создана.
3.4.3 Восстановление данных. Условия: есть хотя бы одна копия.
   1. Выполните restic -r /backup/repo snapshots и выберите нужный снимок.
   2. Выполните restic -r /backup/repo restore latest --target /tmp/restore.
   Результат: данные восстановлены в каталог /tmp/restore.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Пароль хранилища утерян: восстановление невозможно, поэтому храните пароль отдельно.
– Ошибка блокировки: удалите устаревшие блокировки командой restic unlock.
