Руководство пользователя: Mininet (эмуляция домашней сети)

1. Введение
1.1 Область применения. Эмуляция сети умного дома из виртуальных хостов и коммутаторов для тестирования ПО и протоколов MQTT.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Эмуляция сети умного дома из виртуальных хостов и коммутаторов для тестирования ПО и протоколов MQTT. Условия применения: Ubuntu 26.04 LTS; права sudo; ядро с поддержкой сетевых пространств имён.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install mosquitto mosquitto-clients -y
sudo mosquitto_passwd -c /etc/mosquitto/passwd smart
sudo tee /etc/mosquitto/conf.d/smarthome.conf > /dev/null <<'EOF'
sudo systemctl enable --now mosquitto
sudo systemctl restart mosquitto
sudo apt install mininet -y
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/home-env && source ~/home-env/bin/activate
pip install paho-mqtt
sudo apt install docker.io -y
sudo systemctl enable --now docker
mosquitto_pub -h 127.0.0.1 -u smart -P <пароль> -t test -m ok
3.2 Проверка работоспособности. Выполните команды:
sudo docker run -d --name homeassistant --network host -v ~/ha-config:/config ghcr.io/home-assistant/home-assistant:stable
sudo mn --test pingall
curl -I http://localhost:8123
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Сеть запускается командой sudo mn; тестовая топология — командой sudo mn --topo single,3.

4. Описание операций
4.1 Операция 1. Запуск тестовой сети
Условия выполнения: Mininet установлен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните sudo mn --topo single,3.
2. Дождитесь появления приглашения mininet>.
Результат: сеть из трёх хостов запущена.

4.2 Операция 2. Проверка связи между устройствами
Условия выполнения: Сеть запущена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. В приглашении выполните pingall.
2. Убедитесь, что потерь пакетов нет.
Результат: связь между хостами подтверждена.

4.3 Операция 3. Передача данных MQTT
Условия выполнения: На хосте h1 запущен брокер Mosquitto.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. В приглашении выполните h1 mosquitto -d.
2. На хосте h2 выполните h2 mosquitto_sub -h 10.0.0.1 -t home/temp.
3. На хосте h3 выполните h3 mosquitto_pub -h 10.0.0.1 -t home/temp -m 21.
Результат: сообщение доставлено по сети.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Mininet не запускается: очистите остатки сети командой sudo mn -c. Ошибки после аварийного завершения: повторите sudo mn -c и запуск заново.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Используйте sudo mn -c перед каждым новым запуском. Документируйте топологию в файле скрипта Python. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
