Руководство оператора: Mininet (эмуляция домашней сети)
Вариант задания № 23. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Эмуляция сети умного дома из виртуальных хостов и коммутаторов для тестирования ПО и протоколов MQTT.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; права sudo; ядро с поддержкой сетевых пространств имён.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install mosquitto mosquitto-clients -y
sudo mosquitto_passwd -c /etc/mosquitto/passwd smart
sudo tee /etc/mosquitto/conf.d/smarthome.conf > /dev/null <<'EOF'
sudo systemctl enable --now mosquitto
sudo systemctl restart mosquitto
sudo apt install mininet -y
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/home-env && source ~/home-env/bin/activate
pip install paho-mqtt
sudo apt install docker.io -y
sudo systemctl enable --now docker
mosquitto_pub -h 127.0.0.1 -u smart -P <пароль> -t test -m ok
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Сеть запускается командой sudo mn; тестовая топология — командой sudo mn --topo single,3.

3.3 Проверка работоспособности. Выполните команды:
sudo docker run -d --name homeassistant --network host -v ~/ha-config:/config ghcr.io/home-assistant/home-assistant:stable
sudo mn --test pingall
curl -I http://localhost:8123
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Запуск тестовой сети. Условия: Mininet установлен.
   1. Выполните sudo mn --topo single,3.
   2. Дождитесь появления приглашения mininet>.
   Результат: сеть из трёх хостов запущена.
3.4.2 Проверка связи между устройствами. Условия: сеть запущена.
   1. В приглашении выполните pingall.
   2. Убедитесь, что потерь пакетов нет.
   Результат: связь между хостами подтверждена.
3.4.3 Передача данных MQTT. Условия: на хосте h1 запущен брокер Mosquitto.
   1. В приглашении выполните h1 mosquitto -d.
   2. На хосте h2 выполните h2 mosquitto_sub -h 10.0.0.1 -t home/temp.
   3. На хосте h3 выполните h3 mosquitto_pub -h 10.0.0.1 -t home/temp -m 21.
   Результат: сообщение доставлено по сети.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Mininet не запускается: очистите остатки сети командой sudo mn -c.
– Ошибки после аварийного завершения: повторите sudo mn -c и запуск заново.
