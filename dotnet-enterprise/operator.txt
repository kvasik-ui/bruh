Руководство оператора: Docker (контейнеризация приложений .NET)
Вариант задания № 9. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Упаковка приложений .NET в контейнеры и запуск их вместе с базой данных SQL Server.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; права sudo; свободное место не менее 10 ГБ; ОЗУ не менее 4 ГБ.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo snap install rider --classic
sudo apt install dotnet-sdk-8.0 -y
dotnet new webapi -n MyApi
dotnet add package Microsoft.EntityFrameworkCore.Design
dotnet tool install --global dotnet-ef
dotnet build
dotnet list package --vulnerable
sudo apt install docker.io -y
sudo systemctl enable --now docker
sudo docker run -d --name mssql -e "ACCEPT_EULA=Y" -e 'MSSQL_SA_PASSWORD=Strong!Pass123' -p 127.0.0.1:1433:1433 mcr.microsoft.com/mssql/server:2022-latest
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Команды Docker выполняются в терминале. Выйдите из системы и войдите снова после добавления в группу docker.

3.3 Проверка работоспособности. Выполните команды:
dotnet --version
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Сборка образа приложения .NET. Условия: в каталоге проекта есть Dockerfile; Docker запущен.
   1. Выполните docker build -t my-app:1.0 .
   2. Дождитесь окончания сборки.
   3. Проверьте наличие образа командой docker images.
   Результат: образ my-app:1.0 создан.
3.4.2 Запуск контейнера. Условия: образ собран.
   1. Выполните docker run -d -p 8080:8080 --name my-app my-app:1.0.
   2. Проверьте статус командой docker ps.
   Результат: приложение работает в контейнере.
3.4.3 Просмотр журналов контейнера. Условия: контейнер запущен.
   1. Выполните docker logs my-app.
   2. Для потоковой выдачи добавьте флаг -f.
   Результат: журнал выведен, ошибки найдены.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Нет доступа к демону Docker: проверьте службу sudo systemctl status docker и группу docker.
– Контейнер завершается сразу: посмотрите журнал docker logs и код выхода docker ps -a.
