Руководство пользователя: Android Studio и Flutter SDK

1. Введение
1.1 Область применения. Разработка кроссплатформенных мобильных приложений для iOS и Android из единой кодовой базы на языке Dart.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Разработка кроссплатформенных мобильных приложений для iOS и Android из единой кодовой базы на языке Dart. Условия применения: Ubuntu 26.04 LTS, 64-разрядная; процессор с поддержкой виртуализации (VT-x/AMD-V); ОЗУ не менее 8 ГБ; диск не менее 25 ГБ.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install android-studio --classic
sudo snap install flutter --classic
sudo snap install code --classic
sudo apt install clamav clamav-daemon -y
sudo systemctl stop clamav-freshclam && sudo freshclam && sudo systemctl start clamav-freshclam
sudo apt install qemu-system-x86 libvirt-daemon-system -y
sudo usermod -aG kvm,libvirt $USER
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools
sdkmanager --install "platform-tools" "platforms;android-35" "system-images;android-35;google_apis;x86_64"
avdmanager create avd -n test_avd -k "system-images;android-35;google_apis;x86_64"
3.2 Проверка работоспособности. Выполните команды:
flutter doctor
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Запустите Android Studio из меню приложений или командой android-studio.

4. Описание операций
4.1 Операция 1. Создание нового проекта Flutter
Условия выполнения: Установлены Android Studio и Flutter SDK.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. В Android Studio выберите New Flutter Project.
2. Укажите имя проекта и каталог, затем нажмите Create.
3. Дождитесь загрузки зависимостей.
Результат: проект открыт в редакторе и готов к запуску.

4.2 Операция 2. Запуск приложения на эмуляторе
Условия выполнения: Создан проект, настроен эмулятор Android (Device Manager).
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выберите эмулятор в списке устройств на панели инструментов.
2. Нажмите Run (зелёная стрелка).
3. Дождитесь появления приложения на экране эмулятора.
Результат: приложение запущено на эмуляторе.

4.3 Операция 3. Проверка окружения
Условия выполнения: Установлен Flutter SDK.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните в терминале: flutter doctor.
2. Устраните отмеченные ошибки (отсутствующие Android SDK, лицензии).
3. Примите лицензии командой flutter doctor --android-licenses.
Результат: все разделы отчёта flutter doctor отмечены галочкой.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Эмулятор не запускается: проверьте виртуализацию (egrep -c '(vmx|svm)' /proc/cpuinfo) и группу kvm (groups). Ошибки лицензий Android SDK: повторите flutter doctor --android-licenses.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Используйте эмулятор с версией Android, которая нужна пользователям приложения. Регулярно обновляйте Flutter командой flutter upgrade. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
