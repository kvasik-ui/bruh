Руководство пользователя: Unity (движок с AR Foundation)

1. Введение
1.1 Область применения. Разработка AR-приложений для промышленных предприятий: визуализация оборудования и инструкций поверх реального мира.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Разработка AR-приложений для промышленных предприятий: визуализация оборудования и инструкций поверх реального мира. Условия применения: Ubuntu 26.04 LTS; ОЗУ не менее 16 ГБ; видеокарта с поддержкой Vulkan или OpenGL 4.5.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
wget -qO - https://hub.unity3d.com/linux/keys/public | gpg --dearmor | sudo tee /usr/share/keyrings/unityhub.gpg > /dev/null
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/unityhub.gpg] https://hub.unity3d.com/linux/repos/deb stable main" | sudo tee /etc/apt/sources.list.d/unityhub.list
sudo apt update && sudo apt install unityhub -y
sudo apt install dotnet-sdk-8.0 -y
sudo apt install blender -y
3.2 Проверка работоспособности. Выполните команды:
dpkg -l | grep unityhub
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Запустите Unity Hub из меню приложений, установите редактор Unity через раздел Installs.

4. Описание операций
4.1 Операция 1. Создание проекта AR
Условия выполнения: Установлен Unity Hub и редактор Unity.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. В Unity Hub нажмите New project и выберите шаблон AR.
2. Задайте имя и каталог, нажмите Create.
Результат: проект AR создан.

4.2 Операция 2. Добавление AR-объекта
Условия выполнения: Проект открыт в редакторе.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Импортируйте модель оборудования (например, из Blender).
2. Перетащите модель в сцену и настройте её положение.
Результат: объект добавлен в сцену.

4.3 Операция 3. Сборка для устройства
Условия выполнения: Сцена готова.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте File → Build Settings и выберите платформу.
2. Нажмите Build and Run.
Результат: приложение собрано и запущено на устройстве.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Редактор Unity не открывается: проверьте версию драйвера видеокарты. Ошибка сборки для Android/iOS: установите модули платформы через Unity Hub.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Тестируйте AR-сцены в реальных условиях освещения на предприятии. Храните проект в системе контроля версий (Git LFS для моделей). Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
