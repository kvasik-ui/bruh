Руководство оператора: Unity (движок с AR Foundation)
Вариант задания № 24. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Разработка AR-приложений для промышленных предприятий: визуализация оборудования и инструкций поверх реального мира.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; ОЗУ не менее 16 ГБ; видеокарта с поддержкой Vulkan или OpenGL 4.5.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
wget -qO - https://hub.unity3d.com/linux/keys/public | gpg --dearmor | sudo tee /usr/share/keyrings/unityhub.gpg > /dev/null
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/unityhub.gpg] https://hub.unity3d.com/linux/repos/deb stable main" | sudo tee /etc/apt/sources.list.d/unityhub.list
sudo apt update && sudo apt install unityhub -y
sudo apt install dotnet-sdk-8.0 -y
sudo apt install blender -y
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Запустите Unity Hub из меню приложений, установите редактор Unity через раздел Installs.

3.3 Проверка работоспособности. Выполните команды:
dpkg -l | grep unityhub
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Создание проекта AR. Условия: установлен Unity Hub и редактор Unity.
   1. В Unity Hub нажмите New project и выберите шаблон AR.
   2. Задайте имя и каталог, нажмите Create.
   Результат: проект AR создан.
3.4.2 Добавление AR-объекта. Условия: проект открыт в редакторе.
   1. Импортируйте модель оборудования (например, из Blender).
   2. Перетащите модель в сцену и настройте её положение.
   Результат: объект добавлен в сцену.
3.4.3 Сборка для устройства. Условия: сцена готова.
   1. Откройте File → Build Settings и выберите платформу.
   2. Нажмите Build and Run.
   Результат: приложение собрано и запущено на устройстве.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Редактор Unity не открывается: проверьте версию драйвера видеокарты.
– Ошибка сборки для Android/iOS: установите модули платформы через Unity Hub.
