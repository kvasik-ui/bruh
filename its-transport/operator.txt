Руководство оператора: SUMO (симулятор транспортных потоков)
Вариант задания № 30. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Моделирование дорожного движения и визуализация транспортных потоков на городской сети.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; ОЗУ не менее 8 ГБ; Python 3.10 и новее.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo apt install sumo sumo-tools -y
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/its-env && source ~/its-env/bin/activate
pip install pandas statsmodels matplotlib jupyterlab
sudo apt install docker.io -y
sudo systemctl enable --now docker
sudo docker run -d --name grafana -p 127.0.0.1:3000:3000 grafana/grafana
sumo --tripinfo-output tripinfo.xml -c config.sumocfg
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Графический интерфейс запускается командой sumo-gui; расчёт без окна — командой sumo.

3.3 Проверка работоспособности. Выполните команды:
sumo --version
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Запуск готовой модели. Условия: SUMO установлен, есть файлы сети (.net.xml) и маршрутов (.rou.xml).
   1. Выполните sumo-gui -c config.sumocfg.
   2. Нажмите Play для запуска моделирования.
   Результат: модель движения выполняется в окне.
3.4.2 Анализ результатов. Условия: моделирование выполнено с выводом данных.
   1. Выполните анализ файла результатов средствами Python и pandas.
   2. Постройте график средней скорости через matplotlib.
   Результат: график потока построен.
3.4.3 Экспорт данных. Условия: есть результаты моделирования.
   1. Настройте вывод в файл в конфигурации.
   2. Сохраните результаты командой sumo с нужным файлом вывода.
   Результат: данные сохранены для дальнейшей обработки.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Окно SUMO не открывается: проверьте наличие графического окружения (переменная DISPLAY).
– Ошибка сети: проверьте корректность файлов .net.xml командой netconvert.
