Руководство пользователя: SUMO (симулятор транспортных потоков)

1. Введение
1.1 Область применения. Моделирование дорожного движения и визуализация транспортных потоков на городской сети.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Моделирование дорожного движения и визуализация транспортных потоков на городской сети. Условия применения: Ubuntu 26.04 LTS; ОЗУ не менее 8 ГБ; Python 3.10 и новее.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install sumo sumo-tools -y
sudo apt install python3-pip python3-venv -y
python3 -m venv ~/its-env && source ~/its-env/bin/activate
pip install pandas statsmodels matplotlib jupyterlab
sudo apt install docker.io -y
sudo systemctl enable --now docker
sudo docker run -d --name grafana -p 127.0.0.1:3000:3000 grafana/grafana
sumo --tripinfo-output tripinfo.xml -c config.sumocfg
3.2 Проверка работоспособности. Выполните команды:
sumo --version
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Графический интерфейс запускается командой sumo-gui; расчёт без окна — командой sumo.

4. Описание операций
4.1 Операция 1. Запуск готовой модели
Условия выполнения: SUMO установлен, есть файлы сети (.net.xml) и маршрутов (.rou.xml).
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните sumo-gui -c config.sumocfg.
2. Нажмите Play для запуска моделирования.
Результат: модель движения выполняется в окне.

4.2 Операция 2. Анализ результатов
Условия выполнения: Моделирование выполнено с выводом данных.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните анализ файла результатов средствами Python и pandas.
2. Постройте график средней скорости через matplotlib.
Результат: график потока построен.

4.3 Операция 3. Экспорт данных
Условия выполнения: Есть результаты моделирования.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Настройте вывод в файл в конфигурации.
2. Сохраните результаты командой sumo с нужным файлом вывода.
Результат: данные сохранены для дальнейшей обработки.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Окно SUMO не открывается: проверьте наличие графического окружения (переменная DISPLAY). Ошибка сети: проверьте корректность файлов .net.xml командой netconvert.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Калибруйте модель по реальным данным датчиков. Сохраняйте версии конфигураций в Git. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
