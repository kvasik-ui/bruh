Руководство оператора: JaamSim (дискретно-событийное моделирование логистики)
Вариант задания № 31. Ubuntu 26.04 LTS. ГОСТ 19.505-79

1. Назначение программы
Моделирование складских и транспортных процессов цепочки поставок для оценки загрузки и сроков.

2. Условия выполнения
Нужны учётная запись с правами sudo и подключение к интернету. Ubuntu 26.04 LTS; OpenJDK 21; ОЗУ не менее 4 ГБ.

3. Выполнение программы
3.1 Загрузка программы. Команды выполняются по одной:
sudo snap install intellij-idea-community --classic
sudo apt install openjdk-21-jdk maven -y
sudo apt install docker.io -y
sudo systemctl enable --now docker
sudo docker network create odoo-net
sudo docker run -d --name odoo-db --network odoo-net -e POSTGRES_USER=odoo -e POSTGRES_PASSWORD=odoo -e POSTGRES_DB=postgres postgres:16
sudo docker run -d --name odoo --network odoo-net -p 127.0.0.1:8069:8069 -e HOST=odoo-db -e USER=odoo -e PASSWORD=odoo odoo:17
Ответ программы: установка завершается без ошибок.

3.2 Запуск программы. Запуск: java -jar ~/jaamsim/JaamSim.jar.

3.3 Проверка работоспособности. Выполните команды:
java -version
sudo docker ps
Ответ программы: в выводе указаны версии или статус компонентов; ошибок нет.

3.4 Выполнение операций:
3.4.1 Создание модели. Условия: JaamSim запущен.
   1. Откройте модель и добавьте объекты: источники заказов, склады, транспорт.
   2. Соедините объекты связями.
   Результат: структура модели создана.
3.4.2 Запуск моделирования. Условия: модель построена.
   1. Задайте время моделирования.
   2. Нажмите Run.
   Результат: моделирование выполнено.
3.4.3 Анализ результатов. Условия: моделирование завершено.
   1. Откройте отчёты по загрузке объектов.
   2. Сравните варианты модели по срокам поставки.
   Результат: выбран лучший вариант организации потока.

3.5 Завершение работы: сохраните результаты, закройте программу штатным способом (меню «Файл» → «Выход» или Ctrl+Q). Для программ, запущенных в терминале, — Ctrl+C.

4. Сообщения оператору
– Программа не запускается: проверьте версию Java командой java -version.
– Ошибка модели: проверьте связи между объектами и единицы времени.
