Руководство пользователя: JaamSim (дискретно-событийное моделирование логистики)

1. Введение
1.1 Область применения. Моделирование складских и транспортных процессов цепочки поставок для оценки загрузки и сроков.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Моделирование складских и транспортных процессов цепочки поставок для оценки загрузки и сроков. Условия применения: Ubuntu 26.04 LTS; OpenJDK 21; ОЗУ не менее 4 ГБ.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo snap install intellij-idea-community --classic
sudo apt install openjdk-21-jdk maven -y
sudo apt install docker.io -y
sudo systemctl enable --now docker
sudo docker network create odoo-net
sudo docker run -d --name odoo-db --network odoo-net -e POSTGRES_USER=odoo -e POSTGRES_PASSWORD=odoo -e POSTGRES_DB=postgres postgres:16
sudo docker run -d --name odoo --network odoo-net -p 127.0.0.1:8069:8069 -e HOST=odoo-db -e USER=odoo -e PASSWORD=odoo odoo:17
3.2 Проверка работоспособности. Выполните команды:
java -version
sudo docker ps
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Запуск: java -jar ~/jaamsim/JaamSim.jar.

4. Описание операций
4.1 Операция 1. Создание модели
Условия выполнения: JaamSim запущен.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте модель и добавьте объекты: источники заказов, склады, транспорт.
2. Соедините объекты связями.
Результат: структура модели создана.

4.2 Операция 2. Запуск моделирования
Условия выполнения: Модель построена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Задайте время моделирования.
2. Нажмите Run.
Результат: моделирование выполнено.

4.3 Операция 3. Анализ результатов
Условия выполнения: Моделирование завершено.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте отчёты по загрузке объектов.
2. Сравните варианты модели по срокам поставки.
Результат: выбран лучший вариант организации потока.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Программа не запускается: проверьте версию Java командой java -version. Ошибка модели: проверьте связи между объектами и единицы времени.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Сохраняйте разные варианты модели для сравнения. Проверяйте модель на небольшом сроке перед длительным расчётом. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
