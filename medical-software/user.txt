Руководство пользователя: PostgreSQL (система управления базами данных)

1. Введение
1.1 Область применения. Хранение и обработка данных медицинской информационной системы на сервере баз данных.
1.2 Уровень подготовки пользователя. Умение работать в терминале Ubuntu и выполнять команды с sudo, а также знание предметной области задания.

2. Назначение и условия применения
Хранение и обработка данных медицинской информационной системы на сервере баз данных. Условия применения: Ubuntu 26.04 LTS; ОЗУ не менее 4 ГБ; права sudo.

3. Подготовка к работе
3.1 Порядок загрузки программы (команды выполняются по одной):
sudo apt install qtcreator g++ cmake python3 python3-pip -y
sudo apt install postgresql postgresql-contrib -y
sudo systemctl enable --now postgresql
sudo apt install postgresql-16-pgaudit -y
sudo sed -i "s/^#*shared_preload_libraries.*/shared_preload_libraries = 'pgaudit'/" /etc/postgresql/16/main/postgresql.conf
sudo systemctl restart postgresql
sudo apt install dcmtk r-base -y
3.2 Проверка работоспособности. Выполните команды:
g++ --version && psql --version
dcmdump --version
R --version | head -1
Команды должны завершиться без ошибок и вывести версии или статус установленных компонентов.
3.3 Запуск. Сервер работает службой postgresql; подключение командой sudo -u postgres psql.

4. Описание операций
4.1 Операция 1. Создание базы данных и пользователя
Условия выполнения: Служба PostgreSQL запущена.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Откройте консоль: sudo -u postgres psql.
2. Выполните CREATE USER app_user WITH PASSWORD 'пароль';
3. Выполните CREATE DATABASE med_db OWNER app_user;
Результат: база и пользователь созданы.

4.2 Операция 2. Подключение к базе
Условия выполнения: База создана.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните psql -h localhost -U app_user -d med_db.
2. Введите пароль.
Результат: подключение выполнено.

4.3 Операция 3. Резервная копия базы
Условия выполнения: База содержит данные.
Подготовительные действия: убедиться, что условия выполнены, и открыть нужный раздел программы.
Основные действия:
1. Выполните pg_dump -U app_user med_db > med_db.sql.
2. Проверьте размер созданного файла.
Результат: резервная копия сохранена.

4.4 Завершение работы
Условия выполнения: все операции выполнены, результаты сохранены.
Основные действия:
1. Сохранить результаты в программе.
2. Закрыть программу штатным способом: меню «Файл» → «Выход» или сочетание Ctrl+Q.
3. Если на экране появился запрос на подтверждение, подтвердить закрытие программы.
4. Для программ, запущенных в терминале, остановить процесс сочетанием Ctrl+C.
Результат: программа закрыта, данные сохранены.

5. Аварийные ситуации
Сервер не запускается: проверьте журнал sudo journalctl -u postgresql -n 50. Ошибка аутентификации: проверьте файл pg_hba.conf и пароль пользователя.
Восстановление: переустановите программу командами раздела 3.1; данные восстанавливайте из последней резервной копии (например, sudo timeshift --create или архив tar).

6. Рекомендации по освоению
Не используйте суперпользователя для приложения. Регулярно делайте резервные копии и проверяйте их восстановление. Регулярно обновляйте систему командами sudo apt update && sudo apt upgrade -y.
